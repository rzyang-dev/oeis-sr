# 草稿：GF(2) 上自动序列的代数次数

> 状态：经验规律已稳健，严格定理未完成。可作为 note 或论文的一节。

## 背景

Christol 定理：GF(2) 上幂级数 f(x) = Σ a(n)x^n 是代数的 ⟺ 系数序列 a(n) 是 2-自动的。

于是每条 2-自动序列都有一个极小多项式 P(x,y) ∈ GF(2)[x,y]，P(x,f)=0。
**代数次数 deg_y P 是一个自然的不变量，但文献里没有系统统计。**

## 方法

对给定 DFA：生成前 N 项 → 在 GF(2) 上解线性方程组
`Σ_{i≤dx, j≤dy} c_{ij} x^i f^j = 0`，取最小 dy。

**可靠性检验**：同一序列用 N=400 与 N=2000 两次猜度数，103/103 一致。

**三个独立样本一致：约 91–94% 的代数次数是 2 的幂。**

## 关键发现：经典序列全是二次的

对我们研究过的那些序列，**代数次数一律为 2**，与自动机状态数无关（2–7 状态都是）：

| 序列 | 状态数 | 代数次数 |
|---|---|---|
| A010060 / A010059（Thue–Morse） | 2 | 2 |
| A036987（2^k−1 指示） | 3 | 2 |
| A209229 / A255738（2^k 指示） | 3 | 2 |
| A043545（最大位−最小位） | 3 | 2 |
| **A267442（Rule 129 中列）** | 4 | **2** |
| **A267579（Rule 167 中列）** | 4 | **2** |
| A096268（周期倍增） | 4 | 2 |
| A035263（形态词） | 4 | 2 |
| A285383 | 4 | 2 |
| A217586 | 6 | 2 |
| A039982 | 7 | 2 |

即：**这些生成函数在 GF(2)(x) 上是二次的**（满足 a(x)f² + b(x)f + c(x) = 0）。

已验证的例子：

- A036987：`1 + f + x f² = 0`（手算核对）
- A267442：`(x + x³) f² + (1 + x²) f + (1 + x + x³) = 0`
- A267579：`(1 + x² + x³) f² + (x + x² + x³) f + x = 0`

## 严格推导（手算，A036987 与 A267442）

### A036987（2^k−1 指示）

DFA：`δ(0,0)=1, δ(0,1)=0; δ(1,0)=1, δ(1,1)=2; δ(2,·)=2`，输出 `[1,1,0]`。

Mahler 方程（GF(2) 上，用 Frobenius `f(x²) = f(x)²`）：

```
f0 = f1² + x f0²        f1 = f1² + x f2²        f2 = f2² + x f2²
```

- 状态 2 吸收且输出 0 → f2 = 0 ✓（方程自动满足）；
- 于是 f1 = f1² → f1 为常数 = out(1) = 1 ✓；
- 得 **1 + f0 + x f0² = 0** ✓

即 A036987 的生成函数是二次的，**严格证明**（不再依赖 800 项验证）。

### A267442（Rule 129 中列）

已知 A267442(t) = 1 − A036987(t)（t ≥ 1），且 A267442(0) = 1。于是在 GF(2) 上

```
f = x/(1+x) + g        （g = A036987 的生成函数）
```

- g 满足 `1 + g + x g² = 0`（上一节），故 g 在 GF(2)(x) 上二次；
- x/(1+x) 是有理函数；
- 若 f 也有理，则 g = f + x/(1+x) 有理，矛盾（g 的二次方程不可约）。

**所以 deg(f) = 2：Rule 129 中列的生成函数也是二次的，严格证明。**

### 推广形式

对任意 DFA，把 `f_s(x²)` 换成 `f_s(x)²` 得到**代数方程组**

```
f_s = f_{δ(s,0)}² + x·f_{δ(s,1)}²
```

消去辅助变量即得 f0 的方程。这正是我们从 DFA 严格计算极小多项式的算法。

## 猜想

**猜想**：设 a 是 2-自动序列，f 是其 GF(2) 生成函数。则

```
deg_y P(f) 是 2 的幂，除非 f 的"平方结构"被破坏
```

结构性理由：Mahler 方程

```
f_s(x) = f_{δ(s,0)}(x²) + x·f_{δ(s,1)}(x²)
```

每一步都把参数平方；GF(2) 上 f(x²) = f(x)²，所以关系天然带 2^k 结构。

## 局限（必须写进论文）

1. 所有方程都是**猜测 + 稳定验证**，没有一条由 DFA 严格推出；
2. 约 35–80% 的随机自动机在搜索范围内找不到方程（度数太大或 dx 不够）；
3. "度数 = 2 的幂"是经验规律，**不是定理**；
4. OEIS 样本有选择偏差（人工挑选的"漂亮"序列）。

### 手推 A096268 时发现的矛盾（待查）

按图鉴的 A096268 自动机（4 状态，δ(0,0)=1, δ(0,1)=2; δ(1,·)=1; δ(2,0)=3, δ(2,1)=0; δ(3,·)=3，输出 [0,0,1,1]）手推：

```
f1 = 0（吸收态，输出 0）
f3 = 1/(1+x)（吸收态，输出 1）
f0 = x f2²
f2 = 1/(1+x²) + x f0²
=> f0 = x/(1+x²)² + x³ f0⁴     （度数 4）
```

但**猜测法**给 A096268 的度数是 **2**（方程 (1+x²)f + (x+x³)f² + x = 0）。

两者矛盾。可能性：
- 图鉴里的 A096268 自动机与我在 Lean 里用的 δY 不是同一个（状态编号/方向不同）；
- 或者猜测的二次方程是假的（800 项验证仍可能是巧合）。

**这是下一轮必须查清的第一件事**——它直接决定"二次性"结论是否成立。
## 第 10 轮：A096268 的矛盾已解决

决定性测试（图鉴 DFA，10000 项）：

```
(1+x²) f + (x+x³) f² + x = 0      holds: True
手推的四次方程                    holds: False（且测试代码本身有 bug）
```

**结论：A096268 的极小多项式是二次的**，"经典序列都是二次的"成立。

我的手推得到 `f0 = x/(1+x⁴) + x³ f0⁴`（四次），它是二次方程的**推论**（非极小）。
手推过程中漏掉了"f1 = 0 代入后 f2 的平方展开"的化简，导致方程冗余。

### 最终结论（第 11 轮）

正确构造的四次方程在 N=2000 下也成立：

```
(1+x⁴) f + x³(1+x⁴) f⁴ + x = 0    holds: True
(1+x²) f + (x+x³) f² + x = 0      holds: True（极小，度数 2）
```

**两者都成立**：四次方程是二次方程的推论（可约），极小多项式是二次的。

所以 A096268 的度数是 2，**双重确认**（10⁴ 项测试 + 手推一致性）。

教训：手推容易得到非极小的方程；**必须用长前缀测试确认极小性**，
并且"两个方程都成立"不矛盾——四次可以是二次的倍数。
