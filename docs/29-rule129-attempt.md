# Rule 129 中列：一次形式化尝试的记录

> 目标：证明 A267442（Rule 129 中列）等于 A043545。
> 结论：定义已确认并可复现；自相似性证明未完成，属研究级形式化。

## 1. 定义（已确认）

无限网格 ℤ、Rule 129（新细胞 = 1 当且仅当三个邻居全同）、初始单个 1 在 0、
取位置 0 的演化。固定大窗口（±80）模拟与 OEIS 数据**前 32 项完全一致**。

## 2. 等价形式（关键简化）

记 a(t) 为中列。数据表明：

> a(t) = 1 − [t+1 是 2 的幂]

即 a(t) = 1 − A036987(t)（t ≥ 1）。而我们已经证明：
- A036987 = 「2^k − 1 的指示函数」（FrConn.lean）
- A043545 = 最大位 − 最小位（Conn.lean）
- 由此 A043545 = 1 − A036987（对所有 n）

所以**只需再证 a(t) = 1 − A036987(t)**，整条链就闭合了。

## 3. 零集结构（数据）

| t | 零集（区间） | 中列 |
|---|---|---|
| 1 | [−1,1] | 0 |
| 2 | {±1,±2} | 1 |
| 3 | [−3,3] | 0 |
| 5 | [−5,−2]∪[2,5] | 1 |
| 6 | {±1,±2,±5,±6} | 1 |
| 7 | [−7,7] | 0 |
| 14 | {±1,±2,±5,±6,±9,±10,±13,±14} | 1 |
| 15 | [−15,15] | 0 |

规律：零集恰在 t = 2^k − 1 时覆盖 [−t,t]（中列 0）；其余时刻 0 处为 1。

## 4. 尝试过的路线（均未成功）

1. **自相似关系** state(2^k+m−1) ≈ state(m−1)：数值上只在 k=3、m=5,6,7 成立，
   k=4 全部失败。不存在这种简单平移自相似。
2. **边集表示** d(j) = x(j) XOR x(j+1)：初始为相邻两个 1，规则变为
   「d(j)=0 且左右邻居不同」，仍是分形，未见简化。
3. **文献检索**：没有找到 Rule 129 中列的现成刻画；Wolfram Atlas 只有图。

## 5. 需要什么才能完成

一个**重整化引理**：把 t+1 的二进制分解对应到状态的分块结构，例如

> state(2^k + m) 的内部块 = state(m) 的某个变换，边缘由 2^k 决定

这类引理通常需要对「块结构」做强归纳，工作量约等于一条小型 CA 定理
（参考 Sierpinski/rule 90 的形式化难度）。
