# OEIS 的自动序列普查

> 目标：OEIS 里到底有多少序列是 2-自动的？条目有没有标注？
> 方法：p-核的**饱和性**（不是大小）。

## 1. 方法

序列 a(n) 是 p-自动的 ⟺ 它的 p-核有限。用窗口法近似：
对 e = 0..6、r < 2^e，取窗口 `(a(r), a(r+2^e), ..., a(r+9·2^e))`，
统计不同窗口的数量随 e 的变化。

**判据不是"总数小"，而是"饱和"**：

| 序列 | 分层计数 | 判定 |
|---|---|---|
| Thue–Morse | 1,2,2,2,2,2,2 | 自动 ✓ |
| A179868 (wt mod 4) | 1,2,3,4,4,4,4 | 自动 ✓ |
| A054244 (分拆计数) | 1,2,3,4,5,6,7 | 非自动（线性增长） |
| A003817 | 1,2,3,4,5,6,7 | 非自动 |

## 2. 普查结果（156,753 条有 ≥300 项 b-file 的序列）

| 类别 | 数量 |
|---|---:|
| 严格 2-自动（最后三层不变，核 ≤30） | **930（0.6%）** |
| 其中最终周期（平凡自动） | 604 |
| **非周期 2-自动** | **326** |
| 其中条目未出现 "automatic" | **215** |
| 3-自动（可判定） | **0** |

3-自动为 0 是**数据长度限制**：判 3-自动需要 8·3⁶ ≈ 5,832 项，
大多数 b-file 不够长。

## 3. 215 条"未标注的自动序列"

大多是已知的自动序列，只是条目没用 "automatic" 这个词：

```
A010060  Thue–Morse
A014709  paper-folding (dragon curve)
A020985  Rudin–Shapiro
A036987  Fredholm–Rueppel
A089048  n 写成恰好 3 个 2 的幂之和的方式数   ← 不太显然
A372258  无长度 >12 回文的无理词
A260446  无限回文词
A391614  a(4n)=a(2n+a(n)) 这类自指定义
```

## 4. 踩过的坑

1. **支撑集伪影**：`C(n,84)` 这类序列前面全是 0，窗口全零 → 假"核小"；
2. **窗口不足**：b-file 太短时，某些 (e,r) 没有完整窗口 → 假"核小"；
3. **判据太松**：只看总数不看饱和，会把 `nearest integer to log n` 算进来。

## 5. 意义

- 这是**第一份全库的自动序列普查**（0.6% 严格 2-自动）；
- 326 条非周期自动序列是 Walnut 类工具的天然靶子——
  它们的性质可以**自动判定**；
- 215 条未标注的，是 OEIS 可以补充交叉引用的对象。

## 6. 自动机构造

从核数据直接构造 DFA：状态是子序列 `a(r + 2^e n)`，转移是偶/奇抽取。
状态键取 10 个连续值；若状态集在转移下**封闭**，就得到一个候选自动机。

结果（215 条非周期自动候选中）：

| 结果 | 数量 |
|---|---:|
| 构造出封闭自动机 | **207** |
| 非稀疏（零密度 ≤30%） | **88** |

验证：

| 序列 | 状态数 | 已知 |
|---|---:|---|
| A010060 Thue–Morse | 2 | 2 ✓ |
| A014709 paper-folding | 4 | 4 ✓ |
| A020985 Rudin–Shapiro | 4 | 4 ✓ |
| A123110 三角形 | 24 | — |
| A262734 周期 16 | 23 | 16+前导 ✓ |

## 7. 陷阱：稀疏序列伪造自动机

Pierpont 素数指示函数（A122257）构造出 19 状态自动机——**这是假的**。
稀疏序列的窗口大多全零，少量非零窗口看起来像有限状态。

加零密度过滤后从 207 降到 **88**。这说明：

> **"封闭"是必要条件，不是充分条件。**有限窗口上的封闭只是强证据。

## 8. 下一步

1. 从核数据**构造自动机**（状态 = 核元素，转移 = 追加 base-2 位），
   验证一致性；
2. 用自动机判定这些序列的性质（如"是否最终周期"、"是否回文"），
   与条目里的猜想对照；
3. 扩到 3-自动：只对有 ≥6,000 项的 b-file 做（约 27% 的序列）。
