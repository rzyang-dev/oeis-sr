## 1 主公式：子掩码变换

```lean
/-- 任意层大小函数 c 的壳层和 = 对 r t 的子掩码求和。 -/
theorem shell_sum_submask (c : Nat → Nat) (t : Nat) (ht : 1 ≤ t) :
    (shell t).sum c
      = ((subm (r t)) ×ˢ (Finset.range 2)).sum (fun p => c (t - 2 * p.1 - p.2))
```

证明就是把第 13 轮的 `sum_shell_eq_prod`（当时只对 `c = id`）原样搬过来：
同一个双射 `d ↦ ((t−d)/2, (t−d)%2)`，最后一个目标是
`c d = c (t − 2·((t−d)/2) − (t−d)%2)`，`congr 1; omega` 收尾。

**这就是"零点计数是层大小序列的线性泛函"的字面形式。** 一切几何问题之后都变成：
知道 `c_d`，代进去。

## 2 三档增长，三种闭式

| `c_d` 的形状 | 零点数 | 代表几何 |
|---|---|---|
| 常数（`c_d = k`，`c_0 = 1`） | `k·#S − (k−1)·[0∈S]` | 直线（k=2）、射线（k=1） |
| 线性（`c_d = k·d`，`c_0 = 1`） | `k·σ(t) + [0∈S]` | ℤ² 冯诺依曼（k=4）、Moore（k=8）、三角格（k=6） |
| 指数（`c_d = b^d`） | 乘积型（见第 5 节） | b 叉树 |
| 多项式次数 D−1 | `Σ_{d∈S} p(d)`，需 `Σ d^j` | ℤ^D 冯诺依曼/Moore |

线性档的证明（Lean）：

```lean
theorem shell_sum_linear (k t) (ht : 1 ≤ t) :
    (shell t).sum (fun d => if d = 0 then 1 else k * d)
      = k * (shell t).sum id + (if 0 ∈ shell t then 1 else 0)
```

证法：逐点 `(if d = 0 then 1 else k*d) = k*d + (if 0 = d then 1 else 0)`，
然后 `Finset.sum_add_distrib` + `Finset.sum_ite_eq`。

代入第 13 轮的 `sigma_shell` 立刻得到

```
#Z_k(t) = k · #subm(r t) · (2t − 1 − 2 r t) + [t = 2^i − 1]
```

**注意这里没有"整个平面 vs 四分之一平面"的区别**——区别全在 `c_d` 里：
四分之一 Moore 是 `2d+1`（二次型求和），整个 Moore 是 `8d`（线性）。

### 3.1 A169699 的勘误（这次有了新证据）

A169699 的名字是 "Total number of ON cells at stage n of two-dimensional
5-neighbor outer totalistic CA defined by Rule 510"——**规则 510 正是规则 129
的补规则**，所以它的"ON 格数"就是我们的"零点数"。我们算的 52 项与它**全中**。

它条目里唯一的公式写的是：

> `a(n) = (2^{k+1}−1)·2^{1+wt(n)}` for `2^k ≤ n < 2^{k+1}`，**加 1 如果 n 是 2 的幂**

用这个公式核对它自己的 52 项，**9 项不符**：n = 2, 3, 4, 7, 8, 15, 16, 31, 32。
正确的条件是 **加 1 当且仅当 n = 2^i − 1**（此时中心层在壳里，`zero_mem_shell`）。
改过之后 **52 项全对**。

这个"±1"不是打字错误，而是结构性的：`ε = [0 ∈ S(t)]` 就是原点那一层的贡献，
而第 0 层在壳里当且仅当 `t = 2^i−1`。

### 3.2 缺口

奇怪但有信息量的一点：**5 邻版本有条目（A169699），9 邻版本没有**。
A253089 虽然也叫 "9-celled totalistic CA Rule 510"，但它的数据是
`1, 9, 20, 29, 69, 44, 112, 84, …`，与我们的 `1, 9, 24, 49, 56, 112, 112, 225, …`
只在前两项吻合，所以是**另一个** CA（定义或初值不同）。

## 4 这台仪器看不见什么

`subm` 的结构给了壳体一个很强的事实：

```
S(t) = ⊎_{m ⊆ r(t)} { t − 2m , t − 2m − 1 }        （每一对是相邻整数）
```

于是：

**命题.** 每个壳层里偶数层与奇数层一样多。

推论：把任一 `c` 换成 `c + λ·(−1)^d`（偶数层加 λ、奇数层减 λ），
**所有零点数不变**——计数序列看不见这个方向。

数值核对（脚本 278）：

* `Σ_{d∈S(t)}(−1)^d = 0`，t ≤ 5000，0 反例；
* 方程矩阵（T 个方程、T+1 个未知层）**秩恰为 T**，即核空间恒为 1 维
  （T = 4, 6, 10, 14, 20, 30 全部成立）。

所以正确的可观测性定理是：

> **计数序列确定 `c` 到相差一个 λ(−1)^d。固定 `c₀` 之后完全确定。**

Lean 里形式化的是"固定 `c₀` 之后确定"那一半（`shells_determine_levels`，三角性论证：
时刻 t 的方程里只有 `c_t` 是未知的，其余层都更小）。

## 5 树：乘积型闭式

线性档给的是"加性"闭式；指数档给的是**乘性**闭式：

```
#Z_tree(t) = Σ_{m⊆r} (b^{t−2m} + b^{t−2m−1})
           = (b+1) · b^{t−1−2r} · Σ_{m⊆r} (b²)^{r−m}
           = (b+1) · b^{t−1−2r} · ∏_{i ∈ bits(r)} (1 + b^{2^{i+1}})
```

最后一步是"子掩码求和按二进制位分解"：`Σ_{m⊆r} y^{r−m} = ∏_{i∈bits r}(1+y^{2^i})`。
这正是第 1 轮的 `subm_two_mul` / `subm_two_mul_add_one` 在**求和层**的翻版，
只是那时我们只用它算 `Σ m`（线性），没用它做因式分解。

数值：`scripts/279`，b = 2..7、t ≤ 200，**0 处不符**。b = 2 的序列
`3, 6, 15, 24, 60, 102, 255, 384, 960, 1632, …` 不在 OEIS。

这一档的意义：**零点计数对"层大小怎么长"是敏感的，而增长类型决定了闭式的形态**——
多项式 → 加性（`Σ d^j` 的线性组合），指数 → 乘性（二进制因式分解）。

## 8 第 16 轮补：交替核与 popcount 形式化 ✅

两件遗留都做完了。

### 8.1 交替核（`lean/Parity.lean`，4 条定理）

```lean
theorem sub_two_mul_mod (t m) (h : 2*m ≤ t) : (t - 2*m) % 2 = t % 2
theorem sub_two_mul_one_mod (t m) (h : 2*m+1 ≤ t) : (t - 2*m - 1) % 2 = 1 - t % 2

theorem shell_filter_parity_card (t) (ht : 1 ≤ t) :
    (subm (r t)).card = ((shell t).filter (fun d => d % 2 = t % 2)).card

theorem shell_even_odd_count (t) (ht : 1 ≤ t) :
    ((shell t).filter (fun d => d % 2 = 0)).card
      = ((shell t).filter (fun d => d % 2 = 1)).card
```

第三条是核心：**与 t 同奇偶的壳层恰好是第一条臂**（`(subm (r t)).image (t − 2·)`），
用 `Finset.card_bij` 建双射。第四条由"两条臂无交、并为全壳、总大小 = 2·#subm"推出。

工程坑：
* `shell_eq_image` 有假设 `1 ≤ t`，在 `rw` 里必须显式给 `shell_eq_image t ht`，
  否则 Lean 会把它变成一个待证的子目标 `⊢ 1 ≤ t`（而且错误信息会伪装成"case refine_3.ht"）；
* 奇偶计算不要硬推 `Nat.add_mod` 链（会留下 `t % 2 % 2 % 2 = t % 2` 这种嵌套），
  直接 `interval_cases ht : t % 2` 把 `t % 2` 代入目标，两支各一次 `rw` 就完了。

### 8.2 popcount 形式（`lean/Tree.lean` 追加 2 条）

```lean
theorem card_subm_eq_pow_bits (r) : (subm r).card = 2 ^ (bits r).card
theorem card_shell_eq_pow_bits (t) (ht) : (shell t).card = 2 * 2 ^ (bits (r t)).card
```

第一条是 `sum_subm_pow_eq_prod` 取 `y = 1` 的特例（`∏(1 + 1) = 2^{#bits}`）。
这下"计数是 2 的幂"升级成了"**指数就是二进制位数和**"，
第 14 轮里"Mathlib 没有 `popcount` 所以只能停在数值层"的缺口补上了。

### 8.3 剩余

* `Σ_{d∈S} d^j`：j = 0（`card_shell`）、j = 1（`sigma_shell`）已有；
  j = 2 的闭式我已经算出来了（见下），还没形式化：

  ```
  Σ_{m⊆r} m² = N(r² + Q)/4,      N = #subm r,  Q = Σ_{i∈bits r} 4^i
  Σ_{d∈S(t)} d² = N(2K² − 2K + 2Q + 1),   K = t − r t
  ```

  数值核对（`scripts/281`）：r ≤ 300、t ≤ 300，**0 处不符**；并且 ℤ³ 冯诺依曼的零点数
  `4·T2 + 2(#S − ε) + ε` 与脚本 277 的普查值（7, 24, 63, 104, 224, 272, 575, 456, …）逐项吻合。
  这一步之后就自动有 ℤ³ 冯诺依曼/Moore 的显式计数
  （`4d²+2` 与 `24d²+2` 两族）。

## 9 第 17 轮：子掩码的二阶矩形式化 ✅

新文件 `lean/Moments.lean`（3 条定理，0 error / 0 sorry）。

### 9.1 定义与递推

```lean
def Q (r : Nat) : Nat := (bits r).sum (fun i => 4 ^ i)

theorem Q_two_mul (u) : Q (2*u) = 4 * Q u
theorem Q_two_mul_add_one (u) : Q (2*u+1) = 1 + 4 * Q u
```

注意第二个是 `1 + 4·Q u` 而**不是** `Q u + 1`：位整体左移一位，
`4^i` 变成 `4^{i+1} = 4·4^i`，新增的是最低位 `4^0 = 1`。
我第一版写成 `Q u + 1`，代入 u = 1 立刻对不上（`Q 3 = 5` 而不是 `2`）。

### 9.2 主定理

```lean
theorem four_mul_card_sq (r : Nat) :
    4 * (subm r).sum (fun m => m * m) = (subm r).card * (r * r + Q r)
```

即 `Σ_{m⊆r} m² = #subm r · (r² + Q r) / 4`。

证明是对 r 的强归纳，两支：
* 偶支 `r = 2u`：`Σ_{m⊆2u} m² = Σ_{m'⊆u} (2m')² = 4Σ m'²`，
  RHS 用 `Q(2u) = 4Q(u)`、`#subm(2u) = #subm(u)` 对齐；
* 奇支 `r = 2u+1`：`Σ = Σ[8m'² + 4m' + 1] = 8S2 + 4S1 + N`，
  再用归纳假设 `4S2 = N(u)(u²+Q)` 与 `two_mul_sum_subm` 的 `2S1 = N(u)u`。
  最终两边都是 `4N(u)(2u² + 2u + 2Q + 1)`。

工程要点：奇支里要把 `4·(8S2 + 4S1 + N)` 重排成 `8·(4S2) + 8·(2S1) + 4N`
才能把归纳假设和 `two_mul_sum_subm` 代进去（`hshape` 那一步用 `ring`），
之后是纯多项式恒等式。

### 9.3 还没形式化的那一步

壳体本身的二阶矩 `Σ_{d∈S(t)} d²` 需要把 `(t−2m)²` 展开，而 Nat 的截断减法
让 `t² − 4tm + 4m²` 很难直接操作。可行的路线是：

1. 在 ℤ 里做（`push_cast` 之后 `Finset.sum_sub_distrib` 等都能用，最后 `ring`）；
2. 或者用"代入消去减法"的技巧：`have ht : t = (t - 2*m) + 2*m := by omega`，
   然后 `rw [ht]; ring` —— 这样减号消失，恒等式变成纯多项式。

闭式本身已经验证（`scripts/281`，t ≤ 300）：

```
Σ_{d∈S(t)} d² = N·(2K(K−1) + 2Q + 1),     N = #subm(r t),  K = t − r t
```

并且 ℤ³ 冯诺依曼的零点数 `4·Σd² + 2(#S − ε) + ε` 与脚本 277 的普查值逐项吻合。
