## 主定理（数值验证 t ≤ 200 全部单元，零误差）

对 t ≥ 1、任意整数 j：

```
x(t,j) = 0  ⟺  |j| ≤ t  且  ⌊(t−|j|)/2⌋ 是 r(t) 的位子掩码
```

其中 r(t) = t − 2^⌊log₂ t⌋（t 去掉最高位）。t = 0 时 x(0,j) = [j=0]。

等价形式（深度剖面，最干净）：令 d = t − |j|，

```
x(t, t−d) = 1 − [⌊d/2⌋ ⊆ r(t)]
```

即从光锥边缘向内读，第 t 行是 r(t) 的 Gould/Sierpinski 行的补，每个比特重复两次。

## 中列推论

```
x(t,0) = 0  ⟺  ⌊t/2⌋ ⊆ r(t)  ⟺  t = 2^k − 1
```

证明（位论证）：t = 2^K + s，则 ⌊t/2⌋ = 2^{K−1} + ⌊s/2⌋ ⊆ s 要求
位 K−1 在 s 中且 ⌊s/2⌋ ⊆ s；后者等价于 s = 2^j − 1（对所有 j）；
结合 2^{K−1} ≤ s < 2^K 得 s = 2^K − 1，即 t = 2^{K+1} − 1。

## 更优路线：折叠拉伸算子 S（重整化 subagent 发现）

定义 `(S W)(j) = W(⌊|j|/2⌋)`（两倍拉伸并折叠）。则对**所有 t ≥ 1**：

```
V_{2t+1} = S(V_t)      （逐点，所有整数 j）
```

数值验证 t ≤ 340 全部成立。**这一条恒等式推出所有结论**：
- 中列：e_t(0)=1 ⟺ t+2 是 2 的幂 ⟺ V_t(0)=0 ⟺ t = 2^k−1；

### 证明（强归纳，闭合）

令 Φ 为一步 CA，W(−j) := W(j)。

**通用局部引理 (L)**：`Φ²(S(S W)) = S(Φ(S W))` 对**所有** W 成立。
这是有限模式上的局部恒等式（9 格 128 种图案穷举验证 0 失败），不是归纳。

### 为什么这比闭式路线好

- 无需位运算（r(t)、子掩码、XOR 恒等式）；
- 只需一个**有限局部检查** + 强归纳；
- 中列推论直接来自 V_t(0) 的递推。
