# 平移等价普查：自动序列的"原子"结构（第一版）

> 数据：705 条验证过的 DFA 图鉴，其中 195 条非最终周期（`reports/atlas930.json`、
> `reports/periodicity930.json`）。

## 方法

对每条序列用其 DFA 生成前 100 项，比较所有 (a, b, k) 是否满足 `a(n) = b(n+k)`
（k = 1..19，前 70 项匹配）。周期序列会产生大量伪关系，故只统计非周期序列。

## 新发现：Rule 167 = Rule 129 的平移

A267579（Rule 167 中列）与 A267442（Rule 129 中列）相差一个平移：

```
A267579(n) = A267442(n-1) = 1 − A036987(n-1)      (n ≥ 2)
```

A267579 **没有任何评论或公式**——这是一条全新的恒等式，且由我们的定理立即推出。

## ✅ 严格验证完成

用 **DFA 乘积 + 进位冲刷**（不是前缀匹配）重新验证全部 13 对：

还要把进位和 k 的剩余位喂进 b 的 DFA，输出取冲刷后的状态。

## 局限

- 只查了平移 k = 1..19；更大的平移没查；
- 只用 70 项前缀匹配；严格证明需要自动机同构检查（我们已有该工具，但没有跑全量）；
- 只覆盖 195 条非周期序列（图鉴的 1/3）；
- 没有查 XOR/乘积关系（那才是"原子"的另一半）。
