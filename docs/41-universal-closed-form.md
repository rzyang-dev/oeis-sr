# 通用闭式：任意维度、任意对称邻域的"全同"规则

> **主猜想**：设格点上"全同"规则的邻域 N 关于 0 对称且包含 0，
> 令 ‖v‖ 为 N 诱导的范数（Minkowski 泛函），‖v‖ = min{λ ≥ 0 : v ∈ λN}。则
>
>     x_t(v) = 1 − [⌊(t − ‖v‖)/2⌋ ⊆ r(t)]      （‖v‖ ≤ t）
>     x_t(v) = 1                                 （‖v‖ > t）
>
> 其中 r(t) = t 去掉最高位。

## ⚠️ 两次误判的纠正（第 22–23 轮）

第 22 轮曾报告"一维半径 ≥ 3 失败"——**那是窗口污染**。

半径 r 的光锥是 r·t，窗口 N 必须 ≥ r·T。用 N = r·T + 40 重测：

| 几何 | 范数 | 误差 |
|---|---|---|
| 一维 r=1 | \|j\|/1 | 0 / 1599 |
| 一维 r=2 | \|j\|/2 | 0 / 1599 |
| 一维 r=3（N=160） | \|j\|/3 | **0 / 1599** ✓ |
| 一维 r=4（N=200） | \|j\|/4 | **0 / 1599** ✓ |

所以**通用闭式成立**，之前的失败是窗口太小。

### 教训：本会话第三次窗口污染

1. 半径 5 的"临界半径"（第 14 轮）——假；
2. A096268 的四次方程测试（第 10 轮）——代码 bug；
3. 一维半径 3/4 的"失败"（第 22 轮）——窗口太小。

**规则：做 CA 数值实验前，先算光锥 r·T，窗口至少取 r·T + margin。**

最后一行是关键的对照：**范数必须由邻域形状决定**，用错范数立刻失败。

## 推论

1. **中列恒等于 A267442**：v=0 时 ‖v‖=0，公式给出 x_t(0) = 1 − [⌊t/2⌋ ⊆ r(t)]，
   而后者 ⟺ t = 2^k−1。这解释了半径无关性、维数无关性、邻域无关性。

2. **整张图只依赖范数**：不同邻域若诱导同一范数，则时空图完全相同。

3. **中列的代数次数恒为 2**（GF(2) 生成函数二次，见 docs/37）。

## 为什么这个结果是强的

- 它把"Rule 129 的中列结论"提升成了**几何无关性定理**；
- 它解释了之前所有零散观察（半径无关、二维、von Neumann、稀疏对称邻域 {−2,0,2}）；
- 它给出了一个可证明的、结构清晰的陈述：闭式中的 |j| 应替换为邻域诱导的范数。

## 证明（草稿，第 24 轮）

设 N 关于 0 对称且包含 0，‖·‖ 为其 Minkowski 范数（N 是单位球）。

### 引理 1（球面不变性）

对每个 t，x_t(v) 只依赖 ‖v‖。

**归纳**：t=0 时 x_0 是单点 1，球面 {0} 上常值 ✓。
设 x_t(v) = φ_t(‖v‖)。则 x_{t+1}(v) = 1 ⟺ {x_t(u) : u ∈ v+N} 全相等。
由 Minkowski 性质，u ∈ v+N ⟹ |‖u‖ − ‖v‖| ≤ 1，
所以这些值只取 φ_t(d−1), φ_t(d), φ_t(d+1)（d = ‖v‖），
条件只依赖 d ✓。

### 引理 2（径向递推）

φ_{t+1}(d) = 1 ⟺ φ_t(d−1), φ_t(d), φ_t(d+1) 三者相等
（不存在的层忽略；d=0 时只有 0、1 两层，条件为 φ_t(0)=φ_t(1)，
与一维半径 1 在中心处一致）。

边界：φ_0(0)=1，φ_0(d)=0（d>0）；φ_t(d)=1（d>t）。

### 主定理

引理 2 正是**一维半径 1 的 Rule 129**（在深度坐标下），
而它的闭式已证（docs/30）：

    φ_t(d) = 1 − [⌊(t−d)/2⌋ ⊆ r(t)]

代入 d = ‖v‖ 即得主猜想 ✓

### 需要补的细节

1. 证明三个层 d−1, d, d+1 在 v+N 中**都存在**（否则径向递推退化）；
   对 1D 半径 r、Moore、von Neumann 都成立，但对稀疏邻域（如 {−2,0,2}）需要单独检查；
2. 边界 d > t 的处理；
3. 引理 1 的归纳中，"球面常值"需要 N 的对称性（u ∈ N ⟹ −u ∈ N）。

## 证明路线（建议）

1. 对固定的 N，证明 x_t(v) 只依赖 (t, ‖v‖)；
2. 证明沿"射线"（固定 ‖v‖）的演化与半径 1 的情形同构；
3. 用半径 1 的已知闭式（docs/30）完成。

## 局限

- **纯数值，未证明**；
- 一维只测了半径 1..7 的中列，没测整图；
- 二维只测了 Moore 3×3 与 von Neumann 十字；
- {−2,0,2}、{−3,0,3} 等稀疏对称邻域的中列符合，但整图未验证范数形式；
- 范数的精确定义（Minkowski 泛函）是猜测，需要用更多邻域校准。

## 稀疏邻域的补充（第 25 轮）

{−2,0,2}、{−3,0,3} 这类**非凸**稀疏邻域（不是自身范数的单位球）：

```
{−2,0,2}: zeros = 1,3,7,15,31,63,127   （t ≤ 129，N=400）
{−3,0,3}: zeros = 1,3,7,15,31,63,127
```

**中列仍然匹配 2^k−1**，但这些邻域的整图**不**满足范数公式
（因为 N 不是单位球）。

所以两个结论要分开：

| 结论 | 假设 |
|---|---|
| 中列 = 2^k−1 | 只需"对称 + 含 0"（实证） |
| 整图范数公式 | 需要"N 是单位球"（凸） |

中列的普适性更强、更本质——它不依赖凸性。
## ✅ 假设必须加"凸性"（第 26 轮）

把稀疏邻域测到更大 t（N=700）：

| 邻域 | 到 t=219 的零点 | 匹配 2^k−1？ |
|---|---|---|
| {−2,0,2} | 1,3,7,15,31,63,127 | ✓（暂时） |
| **{−4,0,4}** | 1,3,7,15,31,63,127, **177,183,185,187,189,207,211,213** | **✗** |

{−4,0,4} 在 t=177 开始偏离。所以：

> **"中列普适"并非无条件成立。正确的假设是"N 是自身 Minkowski 范数的单位球"（凸）。**

- 凸邻域（区间、Moore、von Neumann）：闭式成立 ✓；
- 稀疏邻域：可能暂时匹配，最终偏离；
- {−2,0,2} 到 t=219 仍匹配，但很可能在更大 t 处偏离（未测）。

这正好补上了证明草稿里"三层都存在"的缺口：
**凸性保证 v+N 在每条射线上的三层 d−1,d,d+1 都存在**，稀疏邻域缺层，递推退化。

所以定理的精确表述是：

> 设 N 是格点上关于 0 对称的**凸**邻域（= 其 Minkowski 范数的单位球），
> 则"全同"规则满足 x_t(v) = 1 − [⌊(t−‖v‖)/2⌋ ⊆ r(t)]。
