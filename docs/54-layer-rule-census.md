## 1 约定：层归约、边界、三种几何

### 1.1 规则编号

    f_r(a,b,c) = (r >> (4a+2b+c)) & 1 ,   a = 层 d−1 的值，b = 层 d 的值，c = 层 d+1 的值

r 就是 Wolfram 编号；256 条 = 三变量布尔函数的全体。真值表按
`(000,001,010,011,100,101,110,111)` 顺序写成 8 位串。

### 1.2 层演化

    x'[d] = f(x[d−1], x[d], x[d+1])      (d ≥ 1)
    x'[0] = f(x[0],   x[0], x[1])        (没有 d−1 层：把缺失层等同于该点自身)
    x_0(0) = 1,  x_0(d) = 0 (d > 0)

比较一律在**视锥** d ≤ t 上做。

**边界约定是规则的一部分，必须固定。** 本报告固定为"缺失层 = 自身"（下称 dup）。
理由：它能复现 129 的机器验证闭式；零填充 `x'[0] = f(0,x[0],x[1])`
在 **t = 5** 就把 129 的闭式破坏掉（t=5 时 dup 给 `110000110`，零填充给 `010000110`）。
镜像补全 `f(x[1],x[0],x[1])` 对 129 也给同样结果，但对一般 f 不同；本报告不采用。
注意：**256/256 这个普查结论与补全方式无关**（只要三种几何用同一个补全），
变的是后面的动力学分类。

### 1.3 三种几何

| 几何 | 层 d 的点数 c_d | 层 d 的邻居 |
|---|---|---|
| 射线 `N` | 1 | d−1, d, d+1（d=0 截断为 0,1） |
| 平面 `Z²` von Neumann | 4d（d≥1），c_0=1 | 自身 + 若干 d−1 / d+1 |
| 无限二叉树 | 2^d | 父(d−1)、自身、两个子(d+1) |

三者都满足 (H1) 邻域只落在 d−1,d,d+1；(H2) 自身在邻域；(H3) d≥1 有 d−1 邻居；
(H4) 每点有 d+1 邻居。**几何的差别全部在 c_d 里**，而层归约不读 c_d。

### 1.4 定理 1（层不变性）【已证】

设 X 是任意满足 (H1)–(H4) 的层结构空间，初值只依赖层号：x_0(y) = p_0(lev y)。
则对**任意** f，x_t(y) = p_t(lev y)，其中

    p_{t+1}(d) = f(p_t(d−1), p_t(d), p_t(d+1))  (d ≥ 1)，
    p_{t+1}(0) = f(p_t(0),   p_t(0), p_t(1))。

**证明.** 对 t 归纳。层 d 的点的邻居值集合恰为 {p_t(d−1), p_t(d), p_t(d+1)}
（d=0 时缺 d−1，按 dup 补 p_t(0)）；它只依赖 d，与邻居的**个数**无关。∎

推论：**"几何无关"不是 129 的性质，而是层值规则的普遍性质**；256 条全部满足。
这也是 docs/44 的结论被推到极致：几何无关性的来源是层结构，不是某条规则。

- 三种几何都用**顶点级**模拟（不是层归约的复算）：平面在 43×43 网格上按显式邻居表
  更新；二叉树物化 2^21−1 个顶点（层 d 用长度 2^d 的数组，父 = 上一层，子 = 交织）。
- 每一步都额外检查"同层所有顶点取值相同"——0 处破坏，这正是定理 1 的结论；
  平面/树的层大小差异（4d, 2^d）完全没有留下痕迹。
- 每个 (rule, t, d) 三元组都比较了射线 / 平面 / 树，共 59 136 个，0 处不符；
  256 条规则里**没有任何一条**出现几何差异。

### 2.2 为什么是 256，以及怎样才可能"很少"

任务里写"若规则只看这三个值、不看每个层有多少个邻居，则它在不同几何下行为一致"——
这句话是对的，而且就是定理 1。所以普查的答案只能是 256/256；**任何**"预期很少"都必须
来自附加条件。把最常见的两个附加条件都算出来：

- **非平凡**（行不是最终常数行）：见 §3，2-收缩族恰好 **8** 条；
- **按轨道合并**：恰好 **2** 条轨道。

如果换成"层归约对**任意**初值都成立"这种更强的"几何无关"，则因为平面/树的同层邻居可以
互不相同，"层 d 的值"在非层常值状态下根本没有定义；只有完全不看 a、c 的 4 条规则
（0、3、12、255）还能谈。这个定义会把 129 也排除掉，不适合本问题。**所以本报告采用
"对层常值初值 + 统一边界补全"作为几何无关的定义。**

### 3.2 收缩常数：定义与扫描

**定义（c-膨胀律）.** 称规则 r 具有收缩常数 c（基准 t_0），若对一切 t ≥ t_0

    row[c·t + c − 1] = D_c(row[t])，   D_c 把每个格子复制 c 份。

等价说法：t 时刻的每个游程（极大同值段）在 c·t+c−1 时刻变成 c 倍长；纪元时刻满足
t_{k+1} = c·t_k + (c−1)，即 t_k = (t_0+1)c^k − 1。c=2, t_0=1 给出 1,3,7,15,… = **2^k−1**；
c=3, t_0=2 给出 2,8,26,80,… = **3^k−1**。这正是任务里"2^k−1 型 / 3^k−1 型"的精确化。

**"非平凡"的判定（可证）.** 若某时刻行恒为 c、背景为 b，则下一行仍恒为常数当且仅当

    f(c,c,c) = f(c,c,b) = f(c,b,b)，   之后 (c,b) → (f(c,c,c), f(b,b,b))。

沿这个二元状态环检查上述条件，就**证明**了"行从 t=2 起恒为常数"（不是窗口观察）。
脚本函数 `constant_row_forever`。

**扫描结果（256 条全扫，行时刻 ≤ 200；脚本 [2.2] 段）**

    c=2 t0=0 :  36 条满足； 4 条非常数行 [90, 94, 122, 126]
    c=2 t0=1 :  72 条满足； 8 条非常数行 [90, 94, 122, 126, 129, 133, 161, 165]
    c=2 t0=2 :  84 条满足； 8 条非常数行 [同上]
    c=3 t0=0 :  36 条满足； 0 条非常数行
    c=3 t0=1 :  84 条满足； 0 条非常数行
    c=3 t0=2 : 100 条满足； 0 条非常数行     ← 3^k−1 链的天然基地
    c=5, c=6, c=7 : 同样 0 条非常数行
    c=4 : 与 c=2 完全相同的 8 条（c=4 律由 c=2 律复合得到）

**结论（【已证】，穷举 + 归纳）：**

- c=2 的非平凡族 **恰为 8 条**；
- c=3,5,6,7 **没有**非平凡解；
- 所有满足 c≥3 律的规则（c=3 时 36/84/100 条，c=6 时 32/64/76 条）都可证明从 t=2 起
  行恒为常数——它们的"收缩"是空间平凡性，不产生任何 3^k−1 图案。

### 3.3 八条规则：真值表、轨道、闭式

真值表顺序 `(000,001,010,011,100,101,110,111)`：

| r | 真值表 | 结构 | 轨道 | 2^k−1 时刻 | 闭式 |
|---|---|---|---|---|---|
| **129** | `10000001` | 全等 | A | 视锥全 **0** | `x = 1 − [⌊(t−d)/2⌋ ⊆ r(t)]` |
| 133 | `10100001` | 全等 + f(010) | A | 全 0 | 同 129（自由位不触发） |
| 161 | `10000101` | 全等 + f(101) | A | 全 0 | 同 129 |
| 165 | `10100101` | 全等 + 两位；= XNOR(a,c) | A | 全 0 | 同 129 |
| **126** | `01111110` | 非全等（= ¬129） | B | 视锥全 **1** | `x = 1 − x^{129}`（t ≥ 1） |
| 122 | `01011110` | 非全等 − f(010) | B | 全 1 | 同 126 |
| 94 | `01111010` | 非全等 − f(101) | B | 全 1 | 同 126 |
| **90** | `01011010` | `a ⊕ c`（Sierpinski） | B | 全 1 | `x = [⌊(t−d)/2⌋ ⊆ r(t)]`（t ≥ 1） |

**结构刻画（【已证】）.** 记"允许三元组"为

    (000), (001), (011), (100), (110), (111)      —— 六个"非孤立"三元组，

即排除 010 与 101（中间值与两端都不同 = 一个孤立格）。则

- 与 129 在六个允许三元组上一致的规则恰有 4 条：**129, 133, 161, 165**；
- 与 90（= 126）在六个允许三元组上一致的规则恰有 4 条：**90, 94, 122, 126**。

之所以"一致"就能"轨道相同"，是因为 **129 的轨道永远不出现 010/101**：

- 129 的死层集是 `S(t) = {t−2m−b : m ⊆ r(t), b ∈ {0,1}}`——**相邻对之并**，
  所以每个死层都有死邻居（无孤立死层 = 无 101）；
- 相邻两对之间要么相邻、要么隔着 ≥3 个活层（无孤立活层 = 无 010）；
- 边界三元组只能是 `(x_0,x_0,x_1)` 或 `(0,0,1)`，也不会是 010/101。

于是 129 的四条"自由位"规则逐时刻相同；126 的轨道是 129 的逐点补（t=1 直接验证，
之后用恒等式 `rule126(¬z) = ¬rule129(z)` 归纳），它的三元组是 129 的补，仍在六个之内，
于是 90/94/122 也逐时刻相同，并且

    x^{126}_t = x^{90}_t = 1 − x^{129}_t   (t ≥ 1)，      死层(129) = 活层(90) = S(t)。

**这就是 90 的闭式**：`x^{90}_t(d) = [⌊(t−d)/2⌋ ⊆ r(t)]`（d ≤ t），d > t 时为 0。
脚本 [3.5] 在 t ≤ 300 上 0 处不符。**同一个集合 S(t) 既是 129 的死层集，又是 90 的活层集。**

### 3.4 2^k−1 家族从哪来（c=2 的证明）

129 的闭式给出（t ≥ 1，d ≤ t，r = r(t)）：

    d ∈ S(2t+1) ⟺ ⌊(2t+1−d)/2⌋ ⊆ 2r+1 ⟺ ⌊(t−⌊d/2⌋)/2⌋ ⊆ r ⟺ ⌊d/2⌋ ∈ S(t)

（用 `2r+1` 的最低位为 1、其余位等于 r）。所以 **S(2t+1) = 2·S(t)**，
即 c=2 膨胀律对 129 成立（t ≥ 1）。再由上一节的轨道相同性，8 条规则全部成立。

- 129 族：`row_1 = 0011…`，于是 `row_{2^k−1} = D_{2^{k−1}}(row_1)` 在视锥内**全 0**；
- 90 族：`row_0 = 1000…`（D 之后是 `1100…`），律从 t=0 就成立，于是 2^k−1 时刻**全 1**。

这就是"2^k−1 型、游程每步缩 2"的确切含义：纪元每翻一倍，每个游程长度乘 2；
129 是"全灭"，90 是"全亮"。

### 3.5 3^k−1：为什么不存在（结构 + 穷举）

**引理（【已证】）.** 若 c-膨胀律对 t ≥ 0 成立，则 `row_{c^k−1} = D_{c^k}(row_0)`，
即视锥内**全 1**（因为 row_0 = 1000…）。归纳：t=0 给 row_{c−1} = D_c(row_0)，
t=c−1 给 row_{c^2−1} = D_c(D_c(row_0))，……

所以：

- 从 t=0 出发的 "c^k−1 家族" 永远是**平凡的全亮家族**——对任何 c、任何规则。
  （c=2 时这就是 row_1 = 1100…，而 129 的真实 row_1 = 0011…，差一步；所以 129 的律
  必须从 t=1 起步，纪元链 1→3→7 恰好还是 2^k−1。）
- c=3 的非平凡基地只能是 **t=2**（链 2→8→26→80 = 3^k−1，base row_2 自由）。
  扫描：c=3, t0=2 在行时刻 ≤ 200 内有 100 条规则通过，但**全部**是"从 t=2 起行恒为常数"
  （可证，见 §3.2），因此它们的 3^k−1 时刻只是"常数行的重复"，没有任何非平凡图案。
- 另一条独立证据：所有死层时刻包含 {2,8,26,80} 的规则共 52 条，**类全为 ALT/DEAD**
  （不是"恰好在这些时刻全死"，而是"一直全死"或"偶数全死"）。

**结论：【已证】非平凡的 3^k−1 家族不存在；"3^k−1 不存在"的结论被加强，而不是被推翻。**
本轮的 8 条规则只给出 2^k−1 家族（129 族全灭 / 90 族全亮）。
