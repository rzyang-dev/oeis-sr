# Rule 129 背后：一个 29 条规则的族

> 探索问题：我们的闭式结构是 Rule 129 独有，还是一族规则共有的？

## 实验 1：拉伸恒等式 V_{2t+1} = S(V_t)

对全部 256 条初等规则、单细胞初值、t ≤ 120 检验：

**30 条规则满足**（逐点、所有整数位置）：

```
0, 8, 32, 40, 64, 72, 96, 104, 126, 128, 129, 136, 151, 159,
160, 161, 168, 183, 191, 192, 200, 215, 222, 223, 224, 232,
247, 253, 254, 255
```

其中 13 条同时满足**通用**局部引理（对所有构型）：
0, 32, 126, 128, 129, 160, 161, 200, 222, 223, 232, 254, 255。

## 实验 2：更强的性质——图只依赖 (⌊d/2⌋, r(t))

我们的闭式形如 x = f(⌊d/2⌋, r(t))，**与 t 的最高位无关**。对全部 256 条规则检验：

**恰好 29 条满足**（与实验 1 几乎重合，少了 253）。

含义：这 29 条规则的时空图都是"Gould 型"——由 t 去掉最高位后的位模式决定。

## 实验 3：这 29 条的结构

它们全部落在**一个 64 元的 XOR 生成空间**里，由 7 个原子布尔函数张成：

| 生成元 | 规则号 | 含义 |
|---|---|---|
| l ⊕ r | 90 | 邻居异或 |
| c | 204 | 复制中心 |
| isolated-1 | 4 | 孤立 1 |
| isolated-0 | 32 | 孤立 0 |
| all-zeros | 1 | 全零邻域 |
| all-ones | 128 | 全一邻域 |
| constant | 255 | 全 1 |

## 实验 4：这些规则的中列在 OEIS 里吗

| 规则 | 中列 | OEIS |
|---|---|---|
| 129 | 1,0,1,0,1,1,1,0,... | **A267442**, A361023 |
| 161 | 同上（已知等价） | A267442 |
| 126 | 1,1,0,1,0,0,0,1,... | A379502 等 |
| 其余 27 条 | **全 0 或全 1** | A000007 / A000012 |

## 结论：族存在，但大部分退化

1. **结构是真的**：29/256 条规则有 Gould 型闭式，且落在 64 元 XOR 空间里；
2. **但绝大多数退化**：27 条的中列是全 0 或全 1；
3. **Rule 129/161 是这个族里唯一非平凡的中列**，126 是它的颜色补；
4. 所以"背后藏着的领域"不是"拉伸性质"，而是更具体的东西：
   **Pascal/Gould mod 2 与初等元胞自动机的交叉**——这是一个经典但狭窄的区域。
