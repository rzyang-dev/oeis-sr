# 文献调研结果：Rule 129 中列的前世今生

> 结论：**恒等式从未被证明**；它 2002 年就被当作事实使用（A071035），
> 2007 年再次被用（A127872），2016 年却被重新列为猜想（A267442）。
> 我们的结果给出第一个证明（两条独立路线）。

## 1. 已有闭式（藏在 OEIS 里，没有论文）

**A071035**（2002，Hans Havermann）= Rule 126 三角形，注释：
`%Y Cf. A036987 (central column).`

**A127872**（2007，P. Deleham）= A039599（Catalan/ballot 三角形）mod 2，注释：
`Sum_{k} T(n,k) x^k = ..., A036987(n), ... for x = ..., 0, ...`

Rule 126 = 255 − 129 是 Rule 129 的颜色补，所以两个三角形逐行互补（t ≥ 1）。
由此得显式闭式（对称形式）：

```
a_129(x,t) = 1 − C(2t+1, t+1+|x|) mod 2      (t ≥ 1)
```

数值验证：t ≤ 300 全部格 + t = 777, 999, 1000, 1023, 1024 的整行，零误差。

## 3. 我们的证明（比闭式更短）

a(0,t) = 1 − C(2t+1,t+1) mod 2。由 C(2t+1,t+1) = C(2t+2,t+1)/2 与
**Kummer/Legendre**：v_2(C(2m,m)) = s_2(m)（m 的二进制 1 的个数），
得 C(2t+1,t+1) 为奇数 ⟺ s_2(t+1) = 1 ⟺ t+1 = 2^k。

所以 a(0,t) = 0 ⟺ t = 2^k − 1 ✓。

## 4. 完整时空图的解释

时空图 = Catalan/ballot 三角形奇偶性的颜色补 = Sierpinski/Pascal-mod-2 带状结构。
所有"2 的幂处自相似"就是这个。中列的 2^k−1 结构是它的边界效应。
