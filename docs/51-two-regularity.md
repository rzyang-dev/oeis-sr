# 51 二正则性：整张计数表是 2-regular，只有树不是

> ## ⚠ 修正（第 54 轮，见 [docs/55](55-rank-law.md)）
>
> 本文第 3 节的秩规律 `rank = deg(c) + 1 + [中心修正]` **作为一般公式是错的**。
> 正确的形式是（docs/55，两侧严格界已证，等式为猜想 A）：
>
> ```
> rank₂(Z_c) = dim span{ A(k,j)ᵀ p } + [δ≠0],   p = c(x) + c(x−1)
> #supp(p) + [δ≠0] ≤ rank₂(Z_c) ≤ #DClose(supp p) + [δ≠0]
> DClose(S) = { l : ∃ i∈S, l ≤ i, l ≡ i (mod 2) }
> ```
>
> 旧的 `deg+1` 只是"p 稠密"（支撑填满每个奇偶类）的特例 —— 13 行真实几何恰好都稠密，
> 所以老表全对。一旦 p 有缺口就失效：`c = x²+x` 给 `p = 2x²`，秩 2 而非 1；
> `c = 2x²+4x+1` 给 `p = 4x²+4x`，秩 3 而非 2。
>
> 根本原因：单个臂矩 `Φ_D` 的 2-kernel 维数是 `⌊D/2⌋+1`（不是 1），
> 所以每个出现过的次数会"带出"整条同奇偶的下降链。
> ### 追加修正（第 55 轮，见 docs/59、docs/60）

这一轮换了一个完全不同的角度：不问"闭式是什么"，而问**"这个序列有多复杂"**。
结论有三层：

1. 整张计数表满足一条**统一的两步行递归**（几何只通过层大小 `c` 进入）；
2. 因此每一行都是 **2-regular** 序列，秩有一个干净的规律：`rank = deg(c) + 1 + [中心修正]`，
   等价地——**ℤ^D 的每条格点序列秩都是 `D + 1`**；
3. **b 叉树是整张表里唯一不是 2-regular 的族**——它的 2-kernel 秩随深度线性增长。

## 1. 两步行递归（`lean/Arm.lean`，6 条定理）

核心对象是"臂"（arm）：壳层是成对的 `{u, u−1}`，取大的那半

```
arm t = { t − 2m : m ⊆ r t }          shell t = arm t ∪ (arm t − 1)
```

（`shell_eq_arm` 已证；`arm t` 全部同奇偶，所以这两个集合不交。）

Lean 里先证了两条 `r` 的二进制递推：

```lean
theorem r_two_mul          (u) (hu : 1 ≤ u) : r (2 * u)     = 2 * r u
theorem r_two_mul_add_one  (u) (hu : 1 ≤ u) : r (2 * u + 1) = 2 * r u + 1
```

于是对任意层大小函数 `c`（**与几何无关**）：

```lean
theorem shell_sum_pair (c) (t) (ht) :
    (shell t).sum c = (subm (r t)).sum (fun m => c (t - 2*m) + c (t - 2*m - 1))

theorem zero_count_two_mul (c) (u) (hu) :
    (shell (2*u)).sum c
      = (subm (r u)).sum (fun m => c (2*(u - 2*m)) + c (2*(u - 2*m) - 1))

theorem zero_count_two_mul_add_one (c) (u) (hu) :
    (shell (2*u+1)).sum c
      = (subm (r u)).sum (fun m => (c (2*(u-2*m)+1) + c (2*(u-2*m)))
                                  + (c (2*(u-2*m)-1) + c (2*(u-2*m)-2)))
```

这就是全部：**时刻 t 的零点数只由 `t` 的奇偶和 `t/2` 决定**，每次折半几何参数
`c` 只是被"拉伸"一次，没有任何别的信息进入。

**臂矩的转移矩阵（第 24 轮已全部 Lean 证明）。** 定义

```lean
def Phi (k t : Nat) : Nat := (subm (r t)).sum (fun m => (t - 2 * m) ^ k)
```

则 `Arm.lean` 里现在有：

| 定理 | 内容 |
|---|---|
| `Phi_eq_arm` | `Φ_k(t) = Σ_{x∈arm t} x^k` |
| `Phi_zero` | `Φ_0(t) = #subm(r t)` |
| **`Phi_two_mul`** | **`Φ_k(2u) = 2^k · Φ_k(u)`**（偶数步是对角矩阵 `diag(2^k)`） |
| **`Phi_two_mul_add_one`** | **`Φ_k(2u+1) = Σ_{i≤k, i≡k(2)} C(k,i) 2^{i+1} Φ_i(u)`**（奇数步只耦合同奇偶的项） |

奇数步的转移矩阵 `M[k][i] = 2^{i+1}·C(k,i)·[i ≡ k (mod 2)]`（`scripts/298` 打印）：

```
k=0: [2, 0,  0,  0,  0,   0,   0]
k=1: [0, 4,  0,  0,  0,   0,   0]
k=2: [2, 0,  8,  0,  0,   0,   0]
k=3: [0, 12, 0, 16,  0,   0,   0]
k=4: [2, 0, 48,  0, 32,   0,   0]
k=5: [0, 20, 0, 160, 0,  64,   0]
k=6: [2, 0, 120, 0, 480,  0, 128]
```

两边都只在**同奇偶**的位置有非零元 —— 这就是"多项式层大小 ⇒ 有限秩"的机制，
而这两条递推本身就是**线性表示**：把 `t` 的二进制位（去掉首位 1）逐位读入，从
`(Φ_0(1),…,Φ_j(1)) = (1,0,…,0)` 出发，每读一位乘 `diag(2^k)` 或乘 `M`。
`scripts/298` 的第 [5] 项核对：这样迭代出来的向量与 `t` 的实际臂矩逐项相同（t < 300，k ≤ 4）。

## 2. 什么叫 2-regular，以及怎么量它

序列 `a` 的 **2-kernel** 是

```
K2(a) = { n ↦ a(2^k n + j) : k ≥ 0, 0 ≤ j < 2^k }
```

若它生成的 `ℤ`-模有限生成，就称 `a` 是 **2-regular**，秩 = 这些序列在 `ℚ` 上的张成维数。
量法：对每个 `k ≤ K`、`j < 2^k` 取前 `M` 项做成向量，做**精确有理高斯消元**求秩
（树那部分值太大，改用 `p = 2^61−1` 模运算；模约化只会**降低**秩，所以"模 p 秩在长"⇒"有理秩在长"）。

## 3. 秩的规律（`scripts/292`、`293`）

纯幂 `c(d) = d^j`（没有中心修正）：

| j | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 实测秩 | 1 | 2 | 3 | 4 | 5 | 6 |
| j + 1 | 1 | 2 | 3 | 4 | 5 | 6 |

带中心修正（`c(0)=1`，`c(d)=d^j` 对 d ≥ 1）：

| j | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 实测秩 | 3 | 4 | 5 | 6 | 7 |
| j + 2 | 3 | 4 | 5 | 6 | 7 |

两个表在 `K = 4..7`、窗口 `M = 40` 上完全平坦（换了 `M = 80` 也不变）。
于是**整张表**：

| 几何 | 层大小次数 j | 中心修正 | 秩 | D+1 |
|---|---|---|---|---|
| 一维直线 | 0 | 有 | **2** | 2 |
| 一维射线 | 0 | 无 | **1** | — |
| ℤ² 5 邻 / 9 邻 / 三角格 | 1 | 有 | **3** | 3 |
| ℤ² 四分之一平面 vN | 1 | 无 | **2** | — |
| ℤ² 四分之一平面 Moore | 1 | 无（且完全因式分解） | **1** | — |
| ℤ³ 两族 | 2 | 有 | **4** | 4 |
| ℤ⁴ 两族 | 3 | 有 | **5** | 5 |
| ℤ⁵ 两族 | 4 | 有 | **6** | 6 |

也就是说：**ℤ^D 的零点序列秩恰好是 `D + 1`**，多出来那一维就是 `ε = [0 ∈ shell t]`
（它本身是秩 1 的 2-automatic 序列，因为 `0 ∈ shell t ⟺ t = 2^i − 1`）。
"复杂度 = 维数"是这张表最干净的定量结论。

## 4. 树：唯一不是 2-regular 的族（`scripts/294`）

b 叉树的零点序列秩**随深度增长**：

```
b = 2:  K=2..9  ->  3, 4, 5, 6, 7, 8, 9, 10
b = 3:  同
b = 4:  同
```

（`M = 60`，`K ≤ 9`，模 `2^61−1`；逐层 +1，没有任何饱和迹象。）所以：

> **b 叉树的零点数不是 2-regular 序列 —— 它没有有限线性表示。**

原因在 `Tree.lean` 的乘积式里就写得明明白白：

```
Σ_{d∈S(t)} b^d = (b+1) · b^(t−1−2r t) · ∏_{i∈bits r t} (1 + b^(2^(i+1)))
```

而 `∏_{i∈bits r}(1 + x^{2^{i+1}}) = Σ_{m⊆r} x^{2m}`（这条递推已在 `Tree.lean` 里证明：
`sum_subm_pow_two_mul : Σ_{m⊆2u} y^m = Σ_{m⊆u} (y*y)^m`），所以每一步折半
（`r(2u) = 2r u`）都会把**底数平方**：`x ↦ x²`。状态里必须带着这个底数，
而底数每层都变，所以状态空间永不封闭 —— 这跟多项式族形成鲜明对照，
后者折半只是把幂次按二项式展开一次，状态维数有限且固定。

（对照：`2^{wt t}` 是秩 1 的 2-regular 序列；`wt(t)·2^{wt t}` 秩 2。方法本身没问题。）

## 5. 这条结论的地位

- **已 Lean 证明（`Arm.lean` 15 条）**：
  * 二步递推：`r_two_mul`、`r_two_mul_add_one`、`shell_eq_arm`、`shell_sum_pair`、
    `zero_count_two_mul`、`zero_count_two_mul_add_one`；
  * 臂矩：`Phi`、`Phi_eq_arm`、`Phi_zero`、`sub_inj`、`sum_arm`、`shell_sum_arm`；
  * **两条转移律**：`Phi_two_mul`（偶数步对角）与 `Phi_two_mul_add_one`（奇数步同奇偶耦合），
    外加二项式恒等式 `pow_pair` 与 `Phi_two_mul_add_one_nat`。
  这些都**与几何无关**，所以对任何层大小函数成立。
- **已数值核实**：秩的规律（`K ≤ 7–9`，窗口 `M = 40–80`）、臂的集合递推、以及
  "按二进制位迭代转移矩阵复现 `Φ_k(t)`"（`scripts/298`，t < 300，k ≤ 4）。
- **未形式化**：秩的规律本身与"树非 2-regular"仍是带限窗口的数值结论，不是定理；
  要变成定理需要 2-正则性理论的形式化，那是这条长线的后半程。

## 6. 一句话

> **折半只让层大小"拉伸"一次，所以多项式族全都 2-regular、秩 = `deg c + 1`（ℤ^D 就是 `D+1`）；
> 而树折半时把底数平方，状态永不封闭，因此唯一地跳出 2-regular。**

## 第 24 轮：分解定理与"行泛函"

上一节把转移矩阵形式化了；这一轮补上**另一半**：零点数怎么写成臂矩的组合。

### 1. Lean 里的分解定理（`Arm.lean` 新增 3 条）

```lean
theorem arm_pos (ht : 1 ≤ t) : ∀ x ∈ arm t, 1 ≤ x

theorem shell_sum_of_poly (c : Nat → Nat) (γ : Nat → Int) (j t : Nat) (ht : 1 ≤ t)
    (hγ : ∀ x, 1 ≤ x → (c x : Int) + (c (x-1) : Int)
        = Σ_{i ∈ range (j+1)} γ i * (x : Int)^i) :
    ((shell t).sum c : Nat) : Int = Σ_{i ∈ range (j+1)} γ i * (Phi i t : Int)

theorem zero_mem_shell_iff (ht : 1 ≤ t) : 0 ∈ shell t ↔ 1 ∈ arm t
```

第一条是"臂里没有 0"（所以每个元素都 ≥ 1，`c (x−1)` 合法）；第二条是
**分解定理**：只要移位和 `c x + c (x−1)` 是次数 ≤ j 的多项式，零点数就是
`Φ_0..Φ_j` 的同一个线性组合 —— 证明只用 `shell_sum_arm` + `Phi_eq_arm`，
**完全不需要二项式展开**。

第三条更妙：**中心指示子就是"1 在臂里"**。因为臂的元素都同奇偶、且 0 永远不在臂里，
所以 `0 ∈ shell t ⟺ 1 ∈ arm t`。这解释了秩律里那个多出来的 +1：
中心修正项天然就是一条秩 1 的 2-automatic 序列。

### 2. 每行的行泛函 γ（`scripts/299_row_functionals.py`）

把层大小写成"中心是 `c_0`、其余是 `p(d)`"，则 `c x + c (x−1) = p x + p(x−1) =: g(x)`
（x ≥ 2），而 x = 1 处差一个常数 `δ = c_0 − p(0)`。拟合出的 γ（即 g 的系数）与 δ：

| 几何 | γ | δ | 维数上界 |
|---|---|---|---|
| 一维直线 | [4] | −1 | 1+1 = 2 |
| 一维射线 | [2] | 0 | 1 |
| ℤ² vN（A169699） | [−4, 8] | 1 | 2+1 = 3 |
| ℤ² Moore | [−8, 16] | 1 | 3 |
| 三角格 | [−6, 12] | 1 | 3 |
| ℤ² 四分之一平面 vN | [1, 2] | 0 | 2 |
| ℤ² 四分之一平面 Moore | [0, 4] | 0 | **1**（γ₀ = 0，掉一维） |
| ℤ³ vN | [8, −8, 8] | −1 | 4 |
| ℤ³ Moore | [28, −48, 48] | −1 | 4 |
| ℤ⁴ Moore | [−80, 224, −192, 128] | 1 | 5 |
| ℤ⁴ vN（3×） | [−24, 56, −24, 16] | 3 | 5 |
| ℤ⁵ Moore | [244, −800, 1120, −640, 320] | −1 | 6 |
| ℤ⁵ vN（3×） | [36, −56, 64, −16, 8] | −3 | 6 |

全部在 t ≤ 200 上逐项核对通过（0 处不符）。注意两条规律：

- `γ_j = 2·(p 的首项系数)`（因为 `g = p(x) + p(x−1)` 的首项系数翻倍）；
- "维数上界" = `#(γ 的非零分量) + [δ ≠ 0]`，与第 3 节实测的秩**逐行相等**。
  四分之一平面 Moore 之所以秩只有 1，正是因为它的 γ₀ = 0，那一维被抵消掉了。

### 3. 现在的完整链条

```
Z_c(t) = Σ_i γ_i Φ_i(t) + δ·[1 ∈ arm t]        （分解定理，Lean）
Φ_k(2u)   = 2^k Φ_k(u)                          （偶数步对角）
Φ_k(2u+1) = Σ_{i≡k(2)} C(k,i) 2^{i+1} Φ_i(u)    （奇数步同奇偶耦合）
```

三者合起来就是**有限状态定理**的内容：状态向量 `(Φ_0,…,Φ_j, ε)` 只有 `j+2` 维，
每读一位 t 的二进制就乘一次固定的整数矩阵。下一轮把它写成对 `k` 的归纳，
得到 `Z_c(2^k·n + r) = Σ_i c_i Φ_i(n) + c·ε(n)` 的显式系数。

### 2. 修正定理

分解定理要求 `c x + c (x−1)` 在 `x ≥ 1` 上都是多项式，但"中心是 1、其余是 p(d)"
的写法在 `x = 1` 处必然破例（那里出现的是 `p(1) + 1` 而不是 `p(1) + p(0)`）。
把这一点单独拿出来：

```lean
theorem shell_sum_of_poly_correction (c γ j δ t) (ht : 1 ≤ t)
    (hγ : ∀ x, 2 ≤ x → c x + c (x-1) = Σ_i γ_i x^i)
    (h1 : c 1 + c 0 = Σ_i γ_i + δ) :
    ↑((shell t).sum c) = Σ_i γ_i ↑(Phi i t) + δ * (if 1 ∈ arm t then 1 else 0)
```

证明的关键就一句话：`arm t` 里的元素都 `≥ 1`，所以除了 `x = 1` 之外都能用
`hγ`；而 `x = 1` 那一点被单独扣成 `δ·[1 ∈ arm t]`。

## 第 26 轮：有限状态定理

这一轮把最后一块拼图补上了：**状态向量 + 每位的转移矩阵 + 迭代**。

### 1. 状态向量与两个转移（`Digits.lean`）

```lean
def X (t : Nat) : Nat → Int := fun k => (Phi k t : Int)
def T0 (v : Nat → Int) : Nat → Int := fun k => 2^k * v k
def T1 (v : Nat → Int) : Nat → Int := fun k =>
  Σ_{i ≤ k, i ≡ k (mod 2)} C(k,i) * 2^(i+1) * v i
```

| 定理 | 内容 |
|---|---|
| `X_one` | `X 1 = (1,1,1,…)`（因为 arm 1 = {1}） |
| `X_two_mul` | `X (2u) = T0 (X u)` |
| `X_two_mul_add_one` | `X (2u+1) = T1 (X u)` |
| `X_digit` | `X t` 由 `t` 的奇偶决定用 `T0` 还是 `T1` 作用在 `X (t/2)` 上 |

### 2. 迭代

定义 `W k r` 为"按 `r` 的低位依次乘上的 `k` 个转移"：

```lean
def W : Nat → Nat → (Nat → Int) → (Nat → Int)
  | 0, _, v => v
  | k+1, r, v => if r % 2 = 0 then T0 (W k (r/2) v) else T1 (W k (r/2) v)
```

则

```lean
theorem X_iterate (k n r) (hn : 1 ≤ n) (hr : r < 2^k) :
    X (2^k * n + r) = W k r (X n)
```

—— 这正是"读 `r` 的二进制位、每读一位乘一个固定矩阵"。

### 3. 三角性：第 i 位只看前 i 位

```lean
theorem W_congr_le (k : Nat) : ∀ (r) {v w} (i),
    (∀ l ≤ i, v l = w l) → ∀ l ≤ i, W k r v l = W k r w l
```

（偶步 `T0` 只碰第 `k` 位；奇步 `T1` 只碰 `i ≤ k`。）这就是**维数上界**的机制：
第 `i` 个分量只依赖 `Φ_0(n),…,Φ_i(n)`。

### 4. 中心位也是数字函数

```lean
theorem zero_mem_digits (k n r) (hn : 1 ≤ n) (hr : r < 2^k) :
    0 ∈ shell (2^k * n + r) ↔ (r + 1 = 2^k ∧ 0 ∈ shell n)
```

即：`ε` 在 `2^k n + r` 处非零，当且仅当 `r = 2^k − 1` 且 `ε(n)` 非零 —— 这正是
"多出来那一维"的全部内容。

### 5. 有限状态定理

```lean
theorem Z_state (k n r …) :
    ↑(Z_c (2^k n + r)) = Σ_i γ_i * (W k r (X n)) i + δ * [1 ∈ arm (2^k n + r)]

theorem Z_state_determined (k r) (hr : r < 2^k) (n n') (hn hn')
    (hPhi : ∀ i ≤ j, Phi i n = Phi i n') (hEps : 0 ∈ shell n ↔ 0 ∈ shell n') :
    (shell (2^k * n + r)).sum c = (shell (2^k * n' + r)).sum c
```

第二条是本轮的主定理：**两个时刻 `n, n'` 只要在 `(Φ_0,…,Φ_j, ε)` 这 `j+2` 个量上一致，
它们在 `2^k n + r` 与 `2^k n' + r` 处的零点数就一致。** 这就是"2-kernel 维数 ≤ j+2"
在**判定形式**下的严格陈述（不需要另建 2-正则性理论）。

### 6. 整条链现在闭合

| 环节 | 定理 |
|---|---|
| 零点数 = 臂上的和 | `shell_sum_arm` |
| = γ 作用于臂矩 + 中心位 | `shell_sum_of_poly_correction` |
| 状态向量 = 臂矩向量 | `X`、`X_one` |
| 每位一个转移 | `X_two_mul`、`X_two_mul_add_one`、`X_digit` |
| 迭代 | `X_iterate` |
| 三角性（维数） | `W_congr_le` |
| 中心位的数字律 | `zero_mem_digits` |
| **判定形式** | **`Z_state_determined`** |
| 13 行的 γ | 13 条 `phi_*`（`Rep.lean`） |

树的两行没有这种描述 —— 它们的层大小是指数，2-kernel 秩无界（`scripts/294`），
正是多项式框架之外的那两行。

## 第 27 轮：显式矩阵与显式线性表示

上一轮给了"状态 + 转移"，这一轮把转移写成**具体的矩阵**，于是系数成为可计算的整数。

### 1. 两个转移矩阵（`Matrix.lean`）

```lean
def M0 (i l : Nat) : Int := if l = i then 2^i else 0
def M1 (i l : Nat) : Int :=
  if l ≤ i ∧ l % 2 = i % 2 then (i.choose l : Int) * 2^(l+1) else 0

theorem T0_apply (hi : i ≤ j) : T0 v i = Σ_{l ≤ j} M0 i l * v l
theorem T1_apply (hi : i ≤ j) : T1 v i = Σ_{l ≤ j} M1 i l * v l
```

### 2. k 步矩阵

按 `r` 的二进制位把 `k` 个矩阵乘起来：

```lean
def A (j : Nat) : Nat → Nat → Nat → Nat → Int
  | 0, _, i, l => if l = i then 1 else 0
  | k+1, r, i, l => Σ_{m ≤ j} (if r % 2 = 0 then M0 i m else M1 i m) * A j k (r/2) m l

theorem W_eq_A (hi : i ≤ j) : W k r v i = Σ_{l ≤ j} A j k r i l * v l
```

### 3. 显式线性表示（目标里的那句话）

```lean
theorem Z_row_linear (k r) (hr : r < 2^k) (n) (hn : 1 ≤ n) :
    ↑(Z_c (2^k n + r))
      = Σ_{l ≤ j} (Σ_{i ≤ j} γ i * A j k r i l) * ↑(Phi l n)
        + δ * (if 1 ∈ arm (2^k n + r) then 1 else 0)
```

**`Φ_l(n)` 的系数就是 `c_l = Σ_i γ_i A j k r i l`** —— 一个可计算的具体整数。
`scripts/301` 对 10 行做了端到端核对（k ≤ 5、n ≤ 40、全部余数），0 处不符。

### 4. 新现象：系数在次数 1 以下是"只看 popcount"的

把 `A` 在不同 `r` 下算出来，会发现：

| 次数 | 系数的形状 |
|---|---|
| j = 0 | `c_0 = γ_0 · 2^{wt(r)}` |
| j = 1 | `c_0 = γ_0 · 2^{wt(r)}`，`c_1 = γ_1 · 2^{k + wt(r)}` |
| j ≥ 2 | 没有这种形式 |

（`scripts/303` 在 k ≤ 6 上核对了 j ≤ 1 的闭式；`wt(r)` 是 `r` 的二进制 1 的个数。）

原因是矩阵的角元：常数位每步乘 1（偶步）或 2（奇步），最高位每步乘 2 或 4，
所以二者都只与"奇数位的个数"有关；而从次数 2 起，`M1` 会在 `i = 2` 与 `i = 1`
之间混合，顺序开始起作用。

**具体反例**（k = 5，popcount 都是 2）：ℤ³ von Neumann 的常数系数
在 `r = 3, 12, 5, 6` 处分别是 `192, 2592, 576, 672` —— 已经不是只看权重，
而是要看**数字的位置**。

### 5. 又一次"次数 2 是门槛"

这个项目里已经出现过三次同样的门槛：

| 现象 | 门槛 |
|---|---|
| 子掩码矩 `Σ m^j` | j ≤ 3 只需 `(r, Q)`；j = 4 需要 `P16`（docs/50） |
| 2-kernel 秩 | 多项式族 = 维数 + 1（docs/51 第 3 节） |
| 表示系数 | j ≤ 1 只看 popcount；j ≥ 2 要看数字位置（本轮） |

三次都指向同一件事：**二次项是第一个让"位置"真正进入统计的阶数。**

### 6. 剩余

- 现在 `A` 是显式定义、`W_eq_A` 是定理，但**每一行的系数还没有作为 Lean 常数算出来**
  （只有 `scripts/301` 的 Python 核对）。把这些系数写成 `def` 并证明它们与 `A` 一致，
  是"显式线性表示"最后一步的规范化工作。
- 树的两行仍不在框架内（层大小指数 ⇒ 非 2-regular，`scripts/294`）。

## 第 28 轮：次数 0 与 1 的行的闭式

上一轮给出"系数 = Σ γ_i A j k r i l"，这一轮把最下面两阶的系数算成闭式。

### 1. 状态向量的前两个分量

```lean
theorem W_zero (hr : r < 2^k) : W k r v 0 = (subm r).card * v 0
theorem W_one  (hr : r < 2^k) : W k r v 1 = 2^k * ((subm r).card * v 1)
```

第一条：常数分量每步乘 1（偶步）或 2（奇步），所以只看到 `r` 的 popcount；
第二条：第一分量每步乘 2 或 4，于是额外多出 `2^k`。

（`subm r` 的基数在偶步不变、奇步翻倍，正是 `card_subm_two_mul` /
`card_subm_two_mul_add_one`。）

### 2. 六行的闭式

```lean
theorem phi_line_explicit (hr : r < 2^k) (hn : 1 ≤ n) :
    Z_line (2^k n + r) = 4 * ((subm r).card * Phi_0 n) - [1 ∈ arm (2^k n + r)]

theorem phi_z2vn_explicit :
    Z_5邻 (2^k n + r) = -4 * ((subm r).card * Phi_0 n)
                      + (8 * 2^k * (subm r).card) * Phi_1 n + [1 ∈ arm (2^k n + r)]

theorem phi_z2moore_explicit :
    Z_9邻 = -8 * ((subm r).card * Phi_0 n) + (16 * 2^k * (subm r).card) * Phi_1 n + [..]

theorem phi_tri_explicit :
    Z_三角 = -6 * ((subm r).card * Phi_0 n) + (12 * 2^k * (subm r).card) * Phi_1 n + [..]

theorem phi_z2orthvn_explicit :
    Z_四分之一vN = (subm r).card * Phi_0 n + (2 * 2^k * (subm r).card) * Phi_1 n

theorem phi_z2orthmo_explicit :
    Z_四分之一Moore = (4 * 2^k * (subm r).card) * Phi_1 n
```

注意 `#subm r = 2^{wt(r)}`，所以这些正是第 27 轮数值观察到的
`c_0 = γ_0·2^{wt}`、`c_1 = γ_1·2^{k+wt}` —— 现在成了定理。
