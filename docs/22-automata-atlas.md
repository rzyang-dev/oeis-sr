# OEIS 自动序列图鉴

> 159 条 2-自动序列的显式 DFA，全部通过"用自动机预测 b-file 全部项"的验证。
> 这是 [21-automatic-census.md](21-automatic-census.md) 的续篇。

## 1. 方法

状态用 \`(e, r)\` 表示，对应子序列 a(r + 2^e n)。
状态签名 = 该子序列前 16 个值；转移 = 追加一个二进制位（LSB-first）。
若状态集在转移下封闭且无冲突，就得到 DFA；输出 = a(r)。

**验证**：用 DFA 预测 b-file 的每一项，与真实值比较。

## 4. 踩到的两个 bug

1. **状态窗口太短**（W=10）：状态被错误合并；
2. **位序反了**：自动机按 LSB-first 构造，预测却用 MSB-first 读位。
   修正后完美率从 18 跳到 159。

这两个 bug 都是"验证失败"暴露出来的——这也说明**留出验证不是可选项**。

## 5. 44 条失败的含义

它们要么是普查的**假阳性**（并非自动），要么是状态合并出错（数据不够）。
这正是图鉴的价值：**它同时给出了"看起来自动但验证不过"的清单**，
这是普查方法本身的误差估计（约 44/203 ≈ 22%）。

## 6. 用自动机判定性质：零密度

自动机的转移矩阵给出**零的渐近密度**：读随机二进制位，收敛到平稳分布，
零输出状态的权重和就是密度。159 条的结果分布：

| 零密度 | 条数 |
|---|---:|
| 0 | 57 |
| 1 | 29 |
| 1/2 | 21 |
| 1/3 | 20 |
| 1/4 | 10 |
| 2/3 | 6 |
| 1/6, 3/4, 5/9, 3/8, 1/5, 1/15 … | 各 1–2 |

## 7. 一个意外发现：16 条"不匹配"其实是收敛慢

把自动机密度与 b-file 的经验密度对照，16 条差 >1%：

| 序列 | 自动机 | 经验 | 说明 |
|---|---:|---:|---|
| A089048 | 1.0 | 0.956 | 3 个 2 的幂之和：非零项只占 O((log n)³) |
| A073267 | 1.0 | 0.990 | 同上 |
| A030300 | 2/3 | 0.546 | 游程长度 2^n，收敛慢 |

**这不是自动机错了，而是极限与有限数据的差别**——
这些序列的零密度趋近极限的速度是多项式级的，2 万项还不够。

> 教训：自动机给出的是**极限**，经验密度是**有限窗口**；两者不一致时，
> 先看收敛速度，再怀疑自动机。

## 8. 3-自动普查（长数据）与 Cobham 检验

只对 **≥6,000 项**的 b-file 做（判定 3-自动需要 8·3⁶ ≈ 5,832 项）：

| 项目 | 数值 |
|---|---:|
| 可判定序列 | 73,060 |
| 分层计数饱和（候选） | **599（0.82%）** |

其中 **77 条**同时也是 2-自动（在图鉴里）。

**Cobham 定理**：对乘法独立的两个底都自动的序列，必须最终周期。
直接检验这 77 条，只有 **7 条**真的最终周期，**70 条不是**。

```
A035263 period-doubling：是 2-自动，不是 3-自动  ← 3-普查假阳性
A096268 period-doubling 变体：同上
A316341 阶乘指示函数：不是 3-自动
```

**结论：窗口法判 3-自动的精度很差。** 可靠流程必须是
"窗口筛选 → 构造 DFA → 用 DFA 预测全部项"，只有图鉴里那 159 条通过了这一关。

## 8a. base-5 普查（浅深度）

受 b-file 长度限制，5-自动只能判到 e ≤ 4（需 8·5⁴ = 5,000 项）：

| 项目 | 数值 |
|---|---:|
| 可判定（≥5000 项） | 78,081 |
| 分层饱和候选 | **335（0.43%）** |
| 同时在 2-自动图鉴中 | 243 |
| 其中最终周期 | 211 |
| **Cobham 违反（非周期）** | **32** |

这 32 条（如 A035263、A096268、A043545）是 2-自动但不是 5-自动，
却被浅深度 5-普查标为候选——**假阳性率 32/243 ≈ 13%**。

与 3-自动（深度 e ≤ 6，假阳性 0/201）对比：**深度越浅，假阳性越高**。
这是一个可量化的方法学结论。

## 8b. 用 Cobham 定理量化 3-自动检测的误差

把**已验证的 636 条 2-自动序列**与 3-自动候选（599 条）取交集：

| 项目 | 数量 |
|---|---:|
| 图鉴条目 | 632（有周期判定的） |
| 同时在 3-自动候选中 | **271** |
| 其中最终周期（Cobham 允许） | 201 |
| **其中非周期（Cobham 禁止）** | **70** |

Cobham 定理是定理，不是猜想：**对乘法独立的两个底都自动 ⇒ 必须最终周期**。
所以这 70 条必然是 3-自动候选里的**假阳性**：

```
A014709 paper-folding     2-自动 ✓  3-自动 ✗（被误判）
A099544 odd part mod 3    2-自动 ✓  3-自动 ✗
A284948 morphic word      2-自动 ✓  3-自动 ✗
```

**量化结果**：在双料候选里，3-自动检测的假阳性率 **≥ 70/271 ≈ 26%**；
在 195 条非周期 2-自动序列里，**36%** 被误判为 3-自动。

> 这是本工作最有方法论价值的一条：**Cobham 定理可以当自动序列检测器的
> 精确度检验器**——用一个已验证的 2-自动机，就能证明某个 3-自动判定是错的。

## 8c. base-3 图鉴 & Cobham 的完美验证

用同样的方法构造 base-3 自动机并预测全部项：

| 项目 | 数量 |
|---|---:|
| 3-自动候选 | 599 |
| 构造出完整 DFA | 461 |
| **完美预测全部项** | **335（56%）** |

然后做决定性检验：把 **271 条双料候选**按 Cobham 分成两组，
看 3-自动机验证的结果：

| 分组 | 完美 | 失败 | 未构造 |
|---|---:|---:|---:|
| **最终周期**（Cobham 允许） | **198** | **0** | 3 |
| **非周期**（Cobham 禁止） | **0** | **42** | 28 |

**结果完美分离**：

- 201 条周期序列里，198 条通过 3-自动机验证，**0 条失败**；
- 70 条非周期序列，**0 条通过**，42 条明确失败。

```
A035263 period-doubling   非周期 → 3-自动机验证失败 (19095/20000)
A014709 paper-folding     非周期 → 构造不出封闭自动机
```

> **Cobham 定理在 OEIS 上被计算验证到 100% 准确**：
> 一个已验证的 2-自动性能**精确预测**该序列是否为 3-自动。

这同时给出了 3-自动检测的误差估计：335/599 ≈ 56% 的真实率，
与 2-自动的 636/930 ≈ 68% 相比更低——符合"底越大越难"的直觉。

## 8d. 留出验证：一次诚实的失败

目标要求"用自动机预测未参与构造的项"。做法：前半段构造 DFA，后半段预测。

| 覆盖门槛 | 条目数 | 预测数 | 准确率 | 完美 |
|---|---:|---:|---:|---:|
| 全部 | 929 | 81,060 | 83.2% | 89 |
| defined ≥ 100 | 56 | 80,683 | 83.1% | 44 |
| defined ≥ 1000 | 31 | 71,269 | 81.2% | 21 |

**问题：覆盖率极低。** 训练半段常常没有覆盖到后半段需要的状态，
转移缺失导致大量"未定义"。

最糟的例子：A016266 等分圆多项式逆序列，周期 > 1500，训练半段全是 1，
自动机退化成 **1 个状态**，后半段准确率 0%。

> **结论：对长周期自动序列，半数据留出不可行。**
> 可靠证据是"全数据构造 + 全项预测 + 最小性"：
> 636 条全项完美、632 条最小化后不变。
