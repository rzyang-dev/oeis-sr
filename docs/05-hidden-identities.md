## 0. 一句话总结

没有破解开放问题。得到的是一张**隐藏关系地图**：在 981 对能同时取到 b-file 的"前 14 项相同"候选里，

其中一对可以用一行证明——探测器找到了一个 OEIS 没有写下来的恒等式。

| 连续一致项数 | 对数 |
|---|---:|

按"是否被明确标记为重复"和"是否有 A 编号互引"过滤后，剩下 **34 对**值得细看。

## 2. 三个案例

### 2.1 A227858 与 A297271：一个可一行证明的恒等式

- **A227858**：Numbers which start and end with the same digit in decimal.
- **A297271**：Numbers whose base-10 digits have equal down-variation and up-variation.

两条序列在 b-file 的 10,000 项上**完全一致**，且互不引用。

证明（一行）：

    设十进制数字为 d_0 d_1 ... d_k，
    上升变化之和 UV = Σ max(0, d_i − d_{i−1})
    下降变化之和 DV = Σ max(0, d_{i−1} − d_i)
    两者相减，正负号抵消，只剩两端：
    UV − DV = d_k − d_0 = 末位 − 首位

所以 UV = DV **当且仅当**首位数字等于末位数字。两条序列描述的是同一个集合，
而 OEIS 的两个条目里都没有提到对方。

（数值验证：50,000 个随机整数，UV−DV = 末位−首位 无一例外。）

### 2.2 A042964 与 A338064：1064 项后分叉，且已被"间接"记录

- **A042964**：Numbers that are congruent to 2 or 3 mod 4.
- **A338064**：Numbers k such that the Enots Wolley sequence A336957(k) is even.

两者一致 1064 项。但 A338064 的评论写着：

> a(n) = A053438(n) for 1 <= n < 1065, but then the two sequences start to differ.

也就是说，这条关系已经被记录，只是记录在**第三条序列**（A053438）名下，
而不是两条序列互相引用。这暴露了"无 A 编号互引"判据的盲区。

### 2.3 A000005 与 A179942：有限尺寸造成的巧合

- **A000005**：τ(n)，约数个数。
- **A179942**：Number of times n appears in a 1000×1000 multiplication table.

一致 1000 项，然后分叉。这不是恒等式，而是"表格只有 1000×1000"造成的有限巧合。
教训：**b-file 的长度可能恰好等于巧合的射程**，复核时要知道数据边界在哪里。

## 3. 逐点分解：18,867 条"可写但没写"的公式

在 514 个核心原子上两两组合（a = b + c、b − c、b × c），在全部项上精确验证，
得到 **18,867 条**分解，例如：

| 序列 | 分解 | 名称 |
|---|---|---|
| A046660 | Ω(n) − ω(n) | 素因子个数（带重数）减（不带重数） |
| A169611 | v2(n) + v3(n) | 只计 2、3 的素因子个数 |
| A080256 | Ω(n) + ω(n) | 两种素因子计数之和 |
| A228495 | Thue–Morse × 奇偶 | 奇数 odious 数的特征函数 |

这些大多数在名称里已经用文字说明，但没有写成 A 编号公式。
它们是符号回归的直接素材：**已知答案的恒等式库**。

## 4. 对符号回归 benchmark 的直接意义

1. **泄漏**：132 对序列在 ≥1000 项上完全一致。如果按序列随机切分训练/测试，
   模型可能记住 A 然后在测试集上"预测"B。必须按等价类分组切分。
2. **有限巧合**：像 τ(n) 与 1000×1000 表这样的对，会让人误判"外推能力"。
3. **去重工具**：`numeric_relation` 表 + 等价类并查集，可以把 298,815 条压到约 287k 条独立序列。

## 5. 诚实的结论

- 这些关系**不是**新数学：绝大多数是"同一个对象的不同描述"（望远镜恒等式、类域论、
  或单纯是重复条目）。
- 但"OEIS 没有把它们连起来"是真的：34 对里，有的确实是漏掉的互引。
- 真正有价值的是**方法**：一个 O(N) 的挖掘器 + b-file 复核，可以在几十分钟内扫完全库，
  把"可疑的同一性"排到前面。剩下的判断需要人（或证明助手）。

## 6. 如果继续，最值得做的三件事

1. 用 `sympy` 或 `Lean` 对 34 对候选做符号验证，把"数值一致"升级成"已证明"。
2. 把 A227858/A297271 这类漏引写成 OEIS 评论（这是对社区有直接价值的小贡献）。
3. 把 18,867 条分解整理成公式库，作为符号回归的 warm start / 评测集。
