## 1. 记号

* `fusc`：Stern 二分序列 A002487，`fusc(0)=0, fusc(1)=1, fusc(2n)=fusc(n), fusc(2n+1)=fusc(n)+fusc(n+1)`。
* `bit_i(x)`：`x` 的第 `i` 位；约定 `i ≥ bitlen(x)` 时 `bit_i(x)=0`。
* `a ⊆ b`：二进制子掩码，即 `(a & b) == a`。
* **超二进制集合** `Hyp(n) := { (u,h) ∈ ℕ² : u & h = 0, u + 2h = n }`
  （即 `n = u + 2h` 且 `u, h` 支集不交 ⟺ `n` 的每个 2 的幂最多用两次的写法，A002487 的经典解释）。
* `T(d) := { i ≥ 0 : bit_i(d) ≠ bit_{i+1}(d) }`：`d` 的"游程边界"集合（等价地：所有 `d`-游程的顶端）。
* `L(d) = (L_1, …, L_k)`：`d` 的二进制极大常值游程长度，**从最低位读到最高位**；起点 `R_j = L_1+…+L_{j-1}`，终点 `t_j = R_j+L_j−1`。
* `K`：连续统（continuant），`K()=1, K(a_1)=a_1, K(a_1…a_k)=a_k K(a_1…a_{k-1}) + K(a_1…a_{k-2})`。
* "1-段"= `u` 的二进制中一段极大连续 1（写作 `[a,b]`，含端点）。

## 2. 定理 1：定义自带的显式双射 `Σ_d ↔ Hyp(d) ⊎ Hyp(d−1)`

**【已证】**

对 `u ∈ Σ_d` 令
```
h(u) := ⌊(d−u)/2⌋ ,      ε(u) := (d−u) mod 2 ,
Φ_d(u) := ( (u, h(u)), ε(u) ) .
```
由定义 `u & h(u) = 0`，且 `u + 2h(u) = d − ε(u)`。于是
* `ε(u)=0` 时 `(u,h(u)) ∈ Hyp(d)`；
* `ε(u)=1` 时 `(u,h(u)) ∈ Hyp(d−1)`。

所以 `Φ_d : Σ_d → (Hyp(d)×{0}) ∪ (Hyp(d−1)×{1})`。**逆映射就是投影到第一坐标** `u`：
* 若 `(u,h) ∈ Hyp(d)`，则 `h = (d−u)/2 = ⌊(d−u)/2⌋` 且 `u & h = 0`、`u ≤ d`，故 `u ∈ Σ_d` 且 `Φ_d(u)=((u,h),0)`；
* 若 `(u,h) ∈ Hyp(d−1)`，则 `d−u = 2h+1` 为奇，`⌊(d−u)/2⌋ = h`，同理 `u ∈ Σ_d` 且 `Φ_d(u)=((u,h),1)`。

两方向互逆，故 `Φ_d` 是双射（其在第一坐标上是恒等，这一点使它成为"定义自带"的规范选择）。
`ε(u) = (d+u) mod 2`，所以标签也可写成 `u` 与 `d` 的奇偶是否相同。∎

**推论 1.1【已证】** 由定理 2，`|Hyp(d)| = fusc(d+1)`、`|Hyp(d−1)| = fusc(d)`，故
```
# { u ∈ Σ_d : u ≡ d (mod 2) } = fusc(d+1) ,
# { u ∈ Σ_d : u ≢ d (mod 2) } = fusc(d) ,
|Σ_d| = fusc(d) + fusc(d+1) .
```
这与 Lean 已证的 `card_pp_stern` / `card_qq_stern`（奇偶两半 = Stern 的两个分量）完全一致，
并且给出了它的**元素级解释**：两半分别就是 `d` 与 `d−1` 的超二进制表示集合。

## 3. 定理 2：`Hyp` 的 Stern 递归，`|Hyp(n)| = fusc(n+1)`

**【已证】**（原来只有 `n < 800` 的【数值验证】，这里给出证明）

**(a) `n = 2m`。** 由 `u = 2m − 2h` 知 `u` 必为偶数，写 `u = 2u'`。此时
`2u' & h = 0 ⟺ u' & (h >> 1) = 0`（因为 `2u' & h = 2·(u' & (h>>1))`），且 `u' + h = m`。按 `h` 的奇偶分两案：
* `h = 2h'`：`u' + 2h' = m`，`u' & h' = 0` ⟺ `(u',h') ∈ Hyp(m)`；对应 `(u,h) = (2u', 2h')`。
* `h = 2h'+1`：`u' + 2h' = m−1`，`u' & h' = 0` ⟺ `(u',h') ∈ Hyp(m−1)`；对应 `(u,h) = (2u', 2h'+1)`。

两像按 `h` 的奇偶不交、合起来覆盖，故
```
Hyp(2m) = 2·Hyp(m)  ⊎  ( 2·Hyp(m−1) + (0,1) ) .          (2a)
```
**(b) `n = 2m−1`。** `u = 2m−1−2h` 必为奇，`u = 2u'+1`；`(2u'+1) & h = 0` 迫使 `h` 偶（否则最低位相撞），`h = 2h'`，
`u' + 2h' = m−1`、`u' & h' = 0`，即
```
Hyp(2m−1) = 2·Hyp(m−1) + (1,0) .                          (2b)
```
**(c) 归纳。** `HB(0)=1, HB(2m)=HB(m)+HB(m−1), HB(2m−1)=HB(m−1)`，与 `fusc` 的两条递归逐项比对：
`HB(2m) = fusc(m+1)+fusc(m) = fusc(2m+1)`，`HB(2m−1) = fusc(m) = fusc(2m)`，基例 `HB(0)=1=fusc(1)`。∎

**推论 2.1（Stern–Brocot 矩阵形式）【已证】** 由 (2a)(2b) 得向量递归
```
(HB(2m−1), HB(2m))   = (HB(m−1), HB(m)) · N_0 ,   N_0 = [[1,0],[1,1]]   ("L"：左子 (p,q)↦(p,p+q))
(HB(2m),   HB(2m+1)) = (HB(m−1), HB(m)) · N_1 ,   N_1 = [[1,1],[0,1]]   ("R"：右子 (p,q)↦(p+q,q))
```
即 `(fusc(n), fusc(n+1)) = (1,1)·∏_{i} N_{bit_i(n)}`，**位从最高位读到最低位（跳过首位 1）**。
`N_0, N_1` 正是 Stern–Brocot 树的左/右子矩阵（行列式 −1 的幺模矩阵）。
【数值验证 n ≤ 2000】（脚本 T2d）。注意方向：**是 MSB→LSB**；LSB→MSB 的写法对应倒数。

## 4. 定理 3：游程 / 连分数正规形（元素级 Stern–Brocot 坐标）

### 4.1 游程判据

**【已证】**（对 `d` 归纳）+【数值验证 d ≤ 2000】

> **定理 3a.** 设 `d ≥ 1`。`u ∈ Σ_d` 当且仅当 `u` 的每个极大 1-段 `[a,b]` 都满足
> `b ∈ T(d)` 且 `d` 在 `[a,b]` 上常值。

*证明.* 先记两条初等数字恒等式（脚本 T3a′ 数值验证 `e ≤ 2000`）：
```
bit_i(2e) = bit_i(2e+1) = bit_{i−1}(e)   (i ≥ 1),
T(2e)   = { i+1 : i ∈ T(e) } ∪ ( {0} 当且仅当 e 奇 ) ,
T(2e+1) = { i+1 : i ∈ T(e) } ∪ ( {0} 当且仅当 e 偶 ) .
```
记 `R(u,d)` 为定理中的断言。对 `d` 归纳，用已证的奇偶递归
`Σ_{2e} = 2Σ_e ⊎ {2v+1 : v∈Σ_e, v+e 奇}`、`Σ_{2e+1} = 2Σ_e ⊎ {2v+1 : v∈Σ_e, v+e 偶}`：

* `u = 2v`（`d = 2e` 或 `2e+1` 都一样）：`u` 的段是 `v` 的段整体上移一位。因 `b+1 ≥ 1`，
  恒等式给出 `b+1 ∈ T(d) ⟺ b ∈ T(e)`，常值条件同时上移，故 `R(2v,d) ⟺ R(v,e)`。这正是递归的**偶部**。
* `u = 2v+1, d = 2e`：设含 0 的段为 `[0,b₀]`。
  - `b₀ = 0`：需 `0 ∈ T(2e)`（⟺ `e` 奇）；且 `u₁ = 0 ⟹ v₀ = 0`，其余段是 `v` 的段平移 ⟹ `R(v,e)`；又 `v+e` 奇（`v₀=0, e₀=1`）。
  - `b₀ ≥ 1`：`u₁ = 1 ⟹ v₀ = 1`；`2e` 在 `[0,b₀]` 常值且 `bit₀(2e)=0` ⟹ `bit₁(2e)=e₀=0`（e 偶）；
    `b₀ ≥ 1` 且 `b₀ ∈ T(2e)` ⟹ `b₀−1 ∈ T(e)`，且 `v` 的低段 = `[0,b₀−1]` ⟹ `R(v,e)`；又 `v+e` 奇（`v₀=1, e₀=0`）。
  两案合起来：`R(2v+1,2e) ⟺ R(v,e) ∧ (v+e 奇)`。这正是递归的**奇部**。
* `u = 2v+1, d = 2e+1`：同上，只是把"`0 ∈ T`"的判据从 "e 奇" 换成 "e 偶"，
  得 `R(2v+1,2e+1) ⟺ R(v,e) ∧ (v+e 偶)`。∎
* 基例 `d = 0`（`T(0)=∅`，只有 `u=0`）、`d = 1`（`T(1)={0}`，`u ∈ {0,1}`）直接验证。

> **推论 3a′（局部数位判据）【已证】** `u ∈ Σ_d ⟺ ∀i: bit_i(u)=1 ⟹ bit_{i+1}(u) ⊕ bit_{i+1}(d) ⊕ bit_i(d) = 1`。
> 证明即"读 u 的位"：若 1-段为 `[a,b]`、`d` 在段上常值、在 `b` 处跳变，
> 则 `i<b` 时 `u_{i+1}=1` 且 `d_{i+1}=d_i`，`i=b` 时 `u_{i+1}=0` 且 `d_{i+1}≠d_i`，两者 XOR 均为 1；
> 反之该判据逐位强制出同样的段结构。
> （这条原来只有 `d ≤ 500` 的【数值验证】，现在由 3a 双向推出，**升级为已证**。）

### 4.2 显式双射到"加权独立集"

**【已证】**（3a 的改写）+【数值验证 d ≤ 2000】

定义
```
WI(d) := { (J, (a_j)_{j∈J}) : J ⊆ {1,…,k},  R_j ≤ a_j ≤ t_j ,
                              且相邻两个指标 j < j' 满足 a_{j'} ≥ t_j + 2 } .
```
> **定理 3b.** 映射 `u ↦ ( J(u), (a_j)_{j∈J(u)} )`，其中 `J(u) = { j : u 有 1-段以 t_j 为顶端 }`、
> `a_j` 是该 1-段的低端，是 `Σ_d → WI(d)` 的双射；逆映射为
> `u = Σ_{j∈J} Σ_{i=a_j}^{t_j} 2^i`。

理由：`T(d) = {t_1,…,t_k}` 恰是 `d` 所有游程的顶端，而"段落在 `d` 的单色游程 `j` 内且顶端为该游程顶端"
⟺ 段 = `[a_j, t_j]` 且 `a_j ≥ R_j`；两段不交且不邻 ⟺ 下一个起点 `≥ t_j+2`。∎

**计数（定理 3d）**【已证，条件于经典连分数对应 3c】+【数值验证 d ≤ 2000】
按 `j = 1..k` 做 DP，令 `A_j` = 命中模式在 `1..j` 上且 `j` 未命中的方案数、`B_j` = `j` 命中的方案数：
```
A_0 = 1, B_0 = 0 ,
A_j = A_{j−1} + B_{j−1} ,        B_j = L_j·A_{j−1} + (L_j−1)·B_{j−1} ,
```
（`j−1` 已命中时 `a_j ≥ t_{j−1}+2 = R_j+1`，故少一个选择）。总数 `A_k+B_k` 数值上等于
`|Σ_d| = fusc(d)+fusc(d+1) = K(L) + K(L[1:])`（连续统 = 连分数的分子与分母之和）。

### 4.3 连分数读法

> 设 `L = (L_1,…,L_k)` 是 `d` 的游程（LSB→MSB）。则
> ```
> fusc(d)/fusc(d+1) = [L_1; L_2; …; L_k]        (d 奇)

> 于是（连续统恒等式：`[a_1;…;a_k] = K(a_1…a_k)/K(a_2…a_k)`）
> `{fusc(d), fusc(d+1)} = {K(L), K(L[1:])}`（作为多重集；哪一个是分子取决于 `d` 的奇偶）。

## 5. 定理 4：加倍提升 = Calkin–Wilf 左子？——对的部分、错的部分、精确障碍

### 5.1 对的部分

**【已证】**（由已证的奇偶递归直接得到）+【数值验证 e ≤ 2000】

```
u ↦ 2u   是  Σ_e ↪ Σ_{2e}  与  Σ_e ↪ Σ_{2e+1}  的单射，
像 = 偶数部分，且 Σ_{2e} 与 Σ_{2e+1} 的偶数部分是同一个集合 2Σ_e .
奇部：Σ_{2e}  的奇部 = { 2v+1 : v ∈ Σ_e, v+e 奇 }     （大小 fusc(e)）
      Σ_{2e+1}的奇部 = { 2v+1 : v ∈ Σ_e, v+e 偶 }     （大小 fusc(e+1)）
```
计数层面 `(p,q)(2e) = (p(e), p(e)+q(e))`、`(p,q)(2e+1) = (p(e)+q(e), q(e))`
（Lean: `card_pp_stern, card_qq_stern`）**正是 Stern–Brocot 的左子 / 右子**。
所以"`d ↦ 2d` 是左子"在**计数**与**单射**两个层面都对。

### 5.2 错的部分与精确障碍

**【已证】**

> `|Σ_{2e}| = |Σ_e| + fusc(e) > |Σ_e|`（`e ≥ 1`），`|Σ_{2e+1}| = |Σ_e| + fusc(e+1)`。

于是**不存在**形如 `Σ_{2e} ≅ Σ_e ⊎ Σ_e`（或 `Σ_{2e+1} ≅ Σ_e ⊎ Σ_e`）的"纯加倍分解"：
第二块的势是 `fusc(e)` 或 `fusc(e+1)`，而 `|Σ_e| = fusc(e)+fusc(e+1)` 比它大。
更精确地：加倍映射只覆盖 `Σ_{2e}`（同样 `Σ_{2e+1}`）的 `|Σ_e|` 个偶数元素，剩余 `fusc(e)`（或 `fusc(e+1)`）个是**奇偶类**
`{v ∈ Σ_e : v+e 奇}`——它的势是 `fusc(e)`，**不是** `|Σ_e|`，所以第二块不可能是 `Σ_e` 的副本。

这就是"纯加倍提升"这条路走不通的精确原因（也解释了为什么不存在把 `u↦2u` 变成左子、
并让 `Σ_{2e}` 成为两个 `Σ_e` 副本的双射）。

### 5.3 正确的递归提升（第二块换成 Hyp）

**【已证】**（§2 + §3 的组合）+【数值验证 e ≤ 2000】

```
σ_{2e}  : Σ_{2e}  ≅  Σ_e  ⊎  Hyp(e−1)
          2v    ↦ (左, v)
          2v+1  ↦ (右, (v, (e−1−v)/2))       要求 v+e 奇
σ_{2e+1}: Σ_{2e+1} ≅  Σ_e  ⊎  Hyp(e)
          2v    ↦ (左, v)
          2v+1  ↦ (右, (v, (e−v)/2))         要求 v+e 偶
```
两个"右"映射正是 §2 的 `u ↦ (u, h)` 限制在奇偶类上，因此这是**规范**的（无需选择）。
迭代到底给出沿 Calkin–Wilf 祖先链 `d, ⌊d/2⌋, ⌊d/4⌋, …, 0` 的分解
```
Σ_d  ≅  {0}  ⊎  ⊎_i Hyp(c_i) ,    n_0 = d,  n_{i+1} = ⌊n_i/2⌋ ,
                                  c_i = n_{i+1}−1 (n_i 偶) / n_{i+1} (n_i 奇)
```
（势相等：`1 + Σ_i fusc(c_i+1) = |Σ_d|`；数值验证 d ≤ 2000）。所以"递归定义的双射"**存在**，
只是递归里出现的第二块必须是 Hyp，不能是 Σ。

### 5.4 附带：`S(2N)=3S(N)`

**【已证】**+【数值验证 N ≤ 2000】由 `A(2e)=A(e)+fusc(e)`、`A(2e+1)=A(e)+fusc(e+1)` 得
`A(2e)+A(2e+1) = 2A(e) + (fusc(e)+fusc(e+1)) = 3A(e)`，求和即 `S(2N)=3S(N)`。

## 7. 为什么 Stern–Brocot 必然出现（机制层面的解释）

1. **局部判据是 2 状态自动机**（推论 3a′）：读 `u` 的位时，"上一位的 XOR 关系"只有两种状态；
   转移矩阵只依赖 `d` 的相邻两位，乘起来是 2×2 幺模矩阵乘积。
2. **同一个矩阵族就是 Stern 的**：`N_0=[[1,0],[1,1]]`、`N_1=[[1,1],[0,1]]` 既是倍增递归的转移（推论 2.1），
   也是 Stern–Brocot 的左/右子。计数只要落在这族矩阵上，就必然是 `fusc`。
3. **`d` 的游程 = 连分数部分商**（定理 3c）：于是 `d` 的二进制形态直接就是
   `fusc(d)/fusc(d+1)` 的连分数形态，`Σ_d` 的计数 = 分子+分母 = 连续统之和。
4. 所以"Stern–Brocot"不是巧合：**`Σ_d` 的元素就是这条连分数上的加权独立集坐标**。

## 10. 附：三个正规形一览

同一批元素的三种写法，可作字典使用：

| 视角 | 对象 | 定理 |
|---|---|---|
| 定义 | `u ∈ [0,d]`，`u & ⌊(d−u)/2⌋ = 0` | 已知 |
| 超二进制 | `(u,h)`，`u & h = 0`，`u+2h ∈ {d−1, d}`（标签 = 哪个） | 定理 1【已证】 |

`|Σ_d|` 的三种算法（都对）：`fusc(d)+fusc(d+1) = fusc(2d+1) = K(L)+K(L[1:])`。
