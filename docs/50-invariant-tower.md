# 50 矩的塔：为什么 j ≤ 3 只需要 r 和 Q，而 j = 4 要新不变量

前几轮把 `Σ_{d∈S} d^j` 一路推到 j = 3，而且 `Σ_{m⊆r} m^j` 一直只用两个不变量
`r` 和 `Q(r) = Σ_{i∈bits r} 4^i`。这一份文档说明：**这是 j ≤ 3 的巧合，不是规律。**

## 1. 生成函数

子掩码 `m = Σ_{i∈bits r} ε_i 2^i`，`ε_i` 独立、各以 1/2 取 0/1。于是

```
Σ_{m⊆r} y^m = ∏_{i∈bits r} (1 + y^{2^i})          （lean/Tree.lean: sum_subm_pow_eq_prod）
```

取 `y = e^s` 得矩母函数 `E[e^{sW}] = ∏_i (1 + e^{s2^i})/2`，其中 `W = m`。
把每个因子写成 `e^{s2^{i−1}}·cosh(s2^{i−1})`，就得到**累积量**：

```
c1 = Σ 2^{i−1}                 = r/2
c2 = Σ 2^{2i−2}                = Q/4
c3 = Σ (3 次累积量)            = 0        ← 对称 Bernoulli 的奇累积量全为 0
c4 = −Σ 16^i / 8               = −P16/8
c5 = 0
c6 = P64/4                     (P_j := Σ_{i∈bits r} 2^{ji})
```

## 2. 矩就是累积量的多项式

```
E[W^1] = μ
E[W^2] = μ² + c2                       → Σ m²  = N(r² + Q)/4
E[W^3] = μ³ + 3μc2                     → Σ m³  = N(r³ + 3Qr)/8
E[W^4] = μ⁴ + 6μ²c2 + 3c2² + c4        → Σ m⁴  = N(r⁴ + 6Qr² + 3Q² − 2P16)/16
E[W^5] = μ⁵ + 10μ³c2 + 15μc2² + 5μc4   → 需要 P16
E[W^6] = μ⁶ + 15μ⁴c2 + 45μ²c2² + 15c2³ + 15μ²c4 + 15c2c4 + c6   → 需要 P16 和 P64
```

（`μ = r/2`，`N = #subm r`。）三阶之所以"干净"，**纯粹是因为 `c3 = 0`**：
奇数次累积量在对称分布下消失，所以 `Σ m³` 只用到 `r` 和 `Q`。
到四阶，`c4 = −P16/8 ≠ 0`，新不变量就进来了。

上面 j = 1..6 的六个公式，在 r ≤ 300 上逐项核对：**全部正确**。

```
[1] submask moments j=1..6, r<=300: OK
```

## 4. P16 不是 (r,Q) 的多项式（scripts/287_p16_not_polynomial.py）

先说清楚 `Q` 有多么"强"：`Q(r)` 是各位数字 0/1 的四进制数，所以 **`Q` 单射**——
它决定了整个位集，从而决定了 `r` 和一切位集不变量。于是"`P16` 是 `(r,Q)` 的
多项式"其实等价于"`P16` 是 `Q` 的多项式"。

取数据点 `(Q(r), P16(r))`，对每个次数 `d ≤ 30` 用过前 `d+1` 个点的唯一插值多项式，
再看它能不能拟合余下的：

```
degree <=  1: first mismatch at r = 3   (298 of 300 wrong)
degree <=  2: first mismatch at r = 4   (297 of 300 wrong)
...
degree <= 30: first mismatch at r = 32  (269 of 300 wrong)
```

规律很整齐：**`d` 次插值恰好在第 `d+2` 个点就错**。所以 `P16` 不是低次多项式
（其实它本就是"数字拉伸"映射 `Σ a_i 4^i ↦ Σ a_i 16^i`，不可能是多项式）。

## 5. 壳体四阶矩（scripts/288_fourth_moment.py）

把 `Σ_S d^4` 按"成对"拆开：`u^4 + (u−1)^4 = 2u^4 − 4u^3 + 6u^2 − 4u + 1`，
再用上面四个子掩码矩展开，得到

```
Σ_{d∈S(t)} d^4 = 2Σu⁴ − 4Σu³ + 6Σu² − 4Σu + N ,     u = t − 2m
```

数值验证（t ≤ 500）：

```
[1] fourth shell moment closed form, t<=500: OK
[2] with the P16 term deleted: wrong for 491 of the 500 t   (first failure t = 3)
[3] the correction is exactly -4 * N * P16: OK - exact for all t <= 500
```

也就是说：**`P16` 在壳体四阶矩里的系数恰好是 `−4N`**，去掉它 500 个里错 491 个
（只有 `r t = 0` 的那些 t 不受影响）。

## 6. 具体后果：ℤ⁵ 是第一个需要 P16 的格（scripts/289_five_dim_moore.py）

ℤ⁵ 的 Moore 层大小是

```
(2d+1)^5 − (2d−1)^5 = 160 d^4 + 80 d^2 + 2 ,      d ≥ 1
```

所以

```
Z^5 Moore:   #Z(t) = 160 M4 + 80 M2 + 2·#shell − ε
```

而 `M4` 正是必须用 `P16` 的那个矩。数值核对（t ≤ 60）通过；把 `P16` 项删掉，
60 个里有 54 个立刻出错（第一个是 t = 3）。

顺带：这条序列 `243, 3124, 16807, 55924, 160808, 315368, 759375, …`
**不在 OEIS 里**（检索结果 null）。

ℤ⁵ 的冯诺依曼方向也一样（层大小 `(4d^4+20d^2+6)/3`，d ≥ 1）：

```
3 · Z = 4 M4 + 20 M2 + 6 #shell − 3 ε
```

它的前几项 `11, 60, 231, 620, 1672, 3032, 7183, 9420, …` 同样**不在 OEIS**。

计数表现在是 **15 行**（`scripts/282_counting_table.py`，t ≤ 60 全部通过，
0 处不符），新增的正是 ℤ⁵ 的两行 —— 也就是**第一次必须动用 P16 的两行**。

## 7. 对"`Σ d^j` 纲领"的含义

| j | 需要的不变量 | Lean |
|---|---|---|
| 0 | — | card_shell |
| 1 | r | sigma_shell |
| 2 | r, Q | shell_sum_sq |
| 3 | r, Q | shell_sum_cube |
| 4 | r, Q, P16 | 未做 |
| 6 | r, Q, P16, P64 | 未做 |

结论有三条：

1. **"只需要 r 和 Q"到 j = 3 为止**。第 4 阶起不变量族开始增长，
   增长律是 `P_j = Σ_{i∈bits r} 2^{ji}`。
2. 这给出一个**清晰的边界**：三维及以下的格（层大小次数 ≤ 3）都只需 `(r,Q)`；
   四维以上、且层大小是四次以上的几何（ℤ⁵ 的两个方向）必须用 `P16`。
3. 所以形式化 `j = 4` 时，不要指望"再写一个 quartic_key 就完事"——
   还要先把 `P16` 的定义、它的二倍/奇偶递推（对应 `bits` 的递归）证出来，
   和 `Q` 那三条（`Q_two_mul`、`Q_two_mul_add_one`、`four_mul_card_sq`）同构。

## 8. 一句话

> **j = 3 处"只用 r 和 Q"的现象是奇累积量消失造成的偶然；第 4 阶的第一个新不变量
> 是 `P16 = Σ_{i∈bits r} 16^i`，它的系数在壳体四阶矩里恰好是 `−4N`。**
