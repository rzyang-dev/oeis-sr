# 定理族方向：Gould 型元胞自动机的穷尽分类

> 问题：Rule 129 的"Gould 行闭式"是一个族现象还是独例？
> 答案：**在全部 256 条初等规则中，只有 3 条（126、129、161）非平凡**，
> 而 161 与 129 等价、126 是它的颜色补。**本质上是一个对象。**

## 判定标准

称规则 R 有 **Gould 型闭式**，若其时空图（单细胞初值）满足

```
x(t, j) 只依赖 (⌊(t−|j|)/2⌋, r(t))，其中 r(t) = t 去掉最高位
```

即：值与 t 的最高位无关，只由深度和"尾部位"决定。

## 穷尽结果（256 条规则）

| 判定 | 条数 |
|---|---|
| 满足 Gould 型依赖（含平凡图） | 29 |
| 其中**非平凡**（既非全 0 也非全 1） | **3**：126, 129, 161 |
| 满足拉伸恒等式 V_{2t+1} = S(V_t)（单细胞） | 30 |
| 满足**通用**局部引理（所有构型） | 29 |

### 三者的关系

- **Rule 161 ≡ Rule 129**（OEIS A267417 的注释已指出"also generated by Rule 161"）；
- **Rule 126 = 255 − 129**（颜色补，时空图逐位互补）；
- 因此非平凡的 Gould 型对象**只有一个**（模颜色补）。

## 结构性观察：29 条的 XOR 生成空间

这 29 条规则全部落在**一个 64 元的 XOR 生成空间**里，由 7 个原子布尔函数张成：

| 生成元 | 规则号 | 含义 |
|---|---|---|
| l ⊕ r | 90 | 邻居异或 |
| c | 204 | 复制中心 |
| 孤立 1 | 4 | 邻域 (0,1,0) |
| 孤立 0 | 32 | 邻域 (1,0,1) |
| 全零邻域 | 1 | (0,0,0) |
| 全一邻域 | 128 | (1,1,1) |
| 常数 | 255 | 全 1 |

## 为什么族很小：与 Christol 方向的连接

Rule 129 中列（A267442）的 GF(2) 生成函数是**二次的**（见 docs/37）：

```
(x + x³) f² + (1 + x²) f + (1 + x + x³) = 0
```

而 Rule 126 是它的补，生成函数只差一个有理项。

**推测**：Gould 型闭式 ⟺ 中列的生成函数二次（或"低次"）。
如果这个等价成立，那就解释了为什么族这么小——二次性是罕见的代数性质。

## 结论（可作为论文的一节）

> 在初等（半径 1、二状态）元胞自动机中，存在 Gould 型闭式的规则构成一个
> **29 条的 XOR 生成集合**，但其中只有**一个非平凡对象**（Rule 129/161，
> 及其颜色补 126）。这与"中列生成函数是二次的"这一代数事实相呼应。

## 局限

- 只覆盖半径 1、二状态、单细胞初值；
- 半径 2 与二维情形**未探索**（目标里提到，但工作量远超本会话）；
