## 一、定理族方向

### 1.1 半径无关性（最强发现，未证明）

> 对每个 r ≥ 1，半径 r 的"全同"规则（窗口 2r+1 个细胞全同）的中列
> **恒等于 A267442**：`x(t,0) = 1 − [t = 2^k − 1]`。

数值：r = 1..7 全部一致（t ≤ 255）。

### 1.2 二维推广（未证明）

Moore 邻域（3×3）的"全同"规则，中心序列同样是 A267442（t ≤ 60）。

### 1.3 整图不同、中列相同

r=1 与 r=2 的整张时空图只有 2573/3835 格相同，但中列一模一样。

### 1.4 初等规则的穷尽分类

全部 256 条半径 1 规则中：
- 29 条满足 Gould 型依赖（值与 t 的最高位无关），
- 其中**只有 3 条非平凡**（126、129、161），
- 而 161 ≡ 129、126 是颜色补 → **非平凡对象只有一个**。
