## 3. 三条证明方向

**(a) A213598（p=7, n≡5）—— eta 商的 freshman's dream**

`A(x) = (x^49;x^49)_∞ / (x;x)_∞`。模 7 用 `F(x)^7 ≡ F(x^7)`，
可把 A(x) mod 7 化成有限个 `F(x)`、`F(x^7)` 的幂的乘积。
若化出来的级数在 n≡5 处系数全为零，就得到证明。
这是可以机械化的（Derksen 型算法），但需要实现多项式/级数的模 p 运算。

**(b) A109085（p=5, n≡3）—— 代数生成函数 + Cartier 算子**

`A(x) = P(x A(x))` 给出代数方程。按 Rowland–Yassawi 的 Cartier 算子方法，
逐次取 `Λ_r` 作用在 A mod 5 上，可以判定哪些 r 的系数为零。
这条路线理论上可完全自动化。

**(c) A051136（p=5, n≡3）—— 广义 Frobenius 分拆**

有已知的 q-级数表示。若其 mod 5 归约落在 `(q;q)_∞` 的某个幂上，
就可以用 Jacobi 三重积或 Watson 的方法处理。

## 3.1 一个关键修正：A051136 是已知定理

按数学陈述重搜之后发现：**Andrews 1984 年就证明了 `cφ₂(5n+3) ≡ 0 (mod 5)`**——
正是 A051136 的同余（本报告把它列为"未记录"）。

它在 OEIS 条目里没写，但在文献里是标准结果（后续还有 Eichhorn–Sellers 的
计算证明、Paule–Radu 的无限族）。

**所以"OEIS 原文未记录"不等于"文献未记录"。** 按 A 编号搜索完全漏掉了它。

更进一步的核查：A051136 的条目**引用了 Andrews 1984 的 Memoir**
（"Generalized Frobenius Partitions", AMS Memoir 301），而那正是证明该同余的文献。

也就是说：

- 条目**不陈述**同余（我们的检测是对的）；
- 但条目**指向了出处**——专家顺着引用就能找到。

## 3.3 闭环成功一例：A156886 已证明

`a(n) = Σ_k C(n,k)C(3n+k,k)`，`a(5m+1) ≡ 0 (mod 5)`。

- 恒等式：`a(n) = [y^(3n)](1+y)^(3n)(2+y)^n`（前 60 项验证）；
- 证明：freshman's dream 拆分，`[y^3](1+y)^3(2+y) = 5 ≡ 0`；
- 938 项 b-file 全部验证；
- OEIS 原文、文献检索均无记录。

完整证明见 [19-a156886-proof.md](19-a156886-proof.md)。
**这条是本轮唯一一条"计算验证 + 完整证明 + 无文献命中"的候选。**

## 4. 诚实的结论

- **计算上**：170 条同余是可靠的（b-file 全类验证）；
- **文献上**：按 A 编号搜索零命中，但按数学陈述搜索命中很多——
  A051136 已被证明是 Andrews 的定理。**"文献未记录"这条腿基本失败**；
- **数学上**：还没有一条完成证明；方向已给出，但每条都需要专门工作。

"未被记录"不等于"新定理"。现在的状态是：

- "OEIS 原文未陈述"：**成立**（170 条），但条目常引用证明它的文献，
  所以这个"未记录"只在最窄的意义上成立；
- "文献未记录"：**未成立**（至少 A051136 是已知定理，其余大概率也在文献里）；
- "完整证明"：没有。

所以目前**没有任何一条可以主张为新定理**。这本身是一个明确的结论。
