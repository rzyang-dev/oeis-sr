# Christol 方向：OEIS 自动序列的代数次数

> 状态：**bug 已修复，结果自洽**。

## Bug 与修复

图鉴里有大量序列的 DFA 输出是 **1/2 取值**（不是 0/1）。在 GF(2) 上对 1/2 值做
多项式运算完全错误（A014709 的 DFA 输出是 [1,1,1,2]）。

修复：只保留 DFA 输出 ⊆ {0,1} 的序列。705 条里跳过 520 条，剩 185 条。

## 结果

| 类别 | 度数 | 条数 |
|---|---|---|
| 周期（有理） | 1 | 58 |
| 非周期 | 2 | 46 |
| 非周期 | 3 | 9 |
| 非周期 | 4 | 19 |
| 非周期 | 8 | 1（A094912） |

搜索范围：dx ≤ 10, dy ≤ 14，前 400 项。12 条周期序列未找到（周期长，dx 不够）。

## 具体方程示例

- **A036987**：`x f² + f + 1 = 0`（手算核对 ✓）
- **A010060**（Thue–Morse）：`x + f + x²f + f² + x f² + x²f² + x³f² = 0`
- **A096268**（周期倍增）：`x + f + x²f + x f² + x³f² = 0`
- **A094912**（度数 8）：含 `f⁸` 项与 `x⁹f⁸` 项

## 意义

这是 OEIS 自动序列在 GF(2) 上代数次数的**第一次系统统计**：

- 有理（最终周期）↔ 度数 1，115 条中 58 条属于此类；
- 非周期序列的度数集中在 **2–4**，只有一条到 8；
- 没有出现度数 5、6、7 —— 这个"缺口"本身可能是结构性的。

## 度数缺口的确认（扩大搜索）

把范围扩到 **states ≤ 12、dx ≤ 12、dy ≤ 18、前 600 项**，非周期 0/1 序列的度数分布：

```
{2: 46, 3: 9, 4: 19, 8: 1}
```

**5、6、7 度依然完全缺失**。唯一的高次案例 A094912（度数 8）的方程在 2000 项下复核通过。

注意：A094912 的 DFA 只有 **5 个状态**，代数次数（8）超过了状态数。

## 合成样本：缺口是假的（重要反转）

为了排除"OEIS 样本太小"的可能，随机生成 4000 个自动机（2–6 状态），
取非周期的 1332 条，算代数次数：

```
{2: 167, 3: 20, 4: 173, 6: 40, 7: 2, 8: 126, 10: 1, 12: 1, 14: 2, 16: 16, fail: 570}
```

**5–7 度的"缺口"不成立**——6 度出现 40 次、7 度 2 次。

所以之前的缺口是 **OEIS 小样本假象**（75 条"漂亮"序列不能代表全体）。

## 新观察：度数偏向 2 的幂

合成样本里：

| 类型 | 条数 |
|---|---|
| 2 的幂（2,4,8,16） | 482 |
| 非 2 的幂（3,6,7,10,12,14） | 66 |

约 **88% 是 2 的幂**。这可能不是巧合：GF(2) 上 Frobenius 是自同构，
Mahler 方程 `f_s = f_{δ(s,0)}(x²) + x f_{δ(s,1)}(x²)` 天然涉及平方，
度数可能被"平方结构"约束。

但 66 条例外说明这不是严格定律（也可能有猜测法的假阳性）。

## 稳定性检验（判定猜测是否可信）

对同一批随机自动机，用 **N=400** 与 **N=2000** 两次独立猜测度数：

```
一致: 103    不一致: 0
```

**103/103 完全一致**。找到的度数不是过拟合——若猜测依赖有限前缀的巧合，
不同 N 会给出不同的最小度数。

稳定度数分布（仅统计两次都成功的）：

```
{1: 26, 2: 27, 3: 3, 4: 28, 6: 5, 8: 13, 12: 1}
```

2 的幂：26+27+28+13 = 94；非 2 的幂：3+5+1 = 9。

**约 91% 是 2 的幂**，且这些度数在 400/2000 项下稳定。

但成功猜出的只有 103/600，方法在大约 83% 的情况下失败（度数超出范围或不存在）。

## 加宽搜索（dy ≤ 24，N = 1200）

```
resolved: 87   failed: 47   degree distribution: {1:21, 2:16, 3:2, 4:19, 6:2, 8:25, 14:1, 16:1}
```

- 失败率从 **83% 降到 35%**（范围加宽确实解决了很多）；
- 2 的幂：**82**；非 2 的幂：**5**（3, 3, 6, 6, 14）；
- **94% 是 2 的幂**，与之前 91% 一致。

### 汇总（三个独立实验）

| 实验 | 样本 | 2 的幂占比 |
|---|---|---|
| OEIS 0/1 非周期 | 75 | 74/75（除 A094912 外全是 2,3,4） |
| 随机 DFA（dy≤14） | 103 | 94/103 = 91% |
| 随机 DFA（dy≤24） | 87 | 82/87 = 94% |

**结论：2 的幂偏好是稳健的经验规律**（三个独立样本一致），但仍有约 5–6% 的例外。

## 局限

- 只覆盖 185 条 0/1 序列（705 条中被跳过 520 条）；
- 方程是"猜测 + 400 项验证"，**不是**由 DFA 严格推出的；
- 12 条周期序列因 dx 范围不够未解出；
- 度数 8 的 A094912 需要独立复验。

## 下一步

1. 用 DFA 的线性表示**严格**推出每条方程（Cartier 算子法），而不只是猜测；
2. 扩大 dx 范围解决 12 条周期序列；
3. 检验"度数 5–7 缺口"是否为真（更多序列、更大范围）。
