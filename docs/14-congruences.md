# 自动同余挖掘：从分拆数到 4,560 条未记录的候选

> 动机：拉马努金最著名的发现之一是分拆函数的同余
> `p(5n+4) ≡ 0 (mod 5)`、`p(7n+5) ≡ 0 (mod 7)`、`p(11n+6) ≡ 0 (mod 11)`。
> 这类模式完全可以用机器在全库上搜索。这一轮做了这件事。

## 1. 方法

对每条有 b-file 的序列，固定素数 p（2,3,5,7,11）和模数 m，检查是否存在剩余类 r，
使得所有 n ≡ r (mod m) 的项都满足 a(n) ≡ 0 (mod p)，且该类至少有 40 个点。

## 2. 先验证：分拆数

A000041 的 b-file 有 10,001 项，直接检查：

| 同余 | 命中 |
|---|---|
| p(5n+4) ≡ 0 mod 5 | 240/240 |
| p(7n+5) ≡ 0 mod 7 | 171/171 |
| p(11n+6) ≡ 0 mod 11 | 109/109 |

方法有效。

## 3. 一个必须修的 bug

第一版按"项的位置"分剩余类，但 b-file 的起始 n 不一定是 0。
位置整体平移只是置换剩余类，**命中总数不变**，但 r 的标签会错位。

例子：A007955（n 的因子之积）最初报 `n ≡ 4 (mod 5)`，实际是 `n ≡ 0 (mod 5)`——
当 n 被 5 整除时因子之积当然被 5 整除，是平凡情形。
改用真实的 n 重算后，这类假阳性被正确归到 r = 0。

**教训：任何"发现"在下结论前，必须能手工复算。**

## 5. 已手工验证的例子

| 序列 | 同余 | 验证 |
|---|---|---|
| A000262 "sets of lists" | **a(n) ≡ 0 mod 11 当且仅当 n ≡ 10 mod 11** | 40/40，类外 0 个零点 |
| A005258 Apéry 型 | a(n) ≡ 0 mod 7 for n ≡ 3 | 136/136 |
| A001515 Bessel y_n(1) | a(n) ≡ 0 mod 7 for n ≡ 2 | 58/58 |

A000262 是最干净的一条：零密度恰为 1/11，且类外没有零点——一个完整的"当且仅当"刻画，
而条目文本里没有写。

## 6. 656 条"当且仅当"型

若某序列的零点密度恰好约为 1/p（±0.02），说明**零点全部落在这一个剩余类里**，
即 `a(n) ≡ 0 (mod p) ⇔ n ≡ r (mod p)`。共 **872 条命中、656 条序列**。

其中一部分是平凡可解释的，例如 A052750 `(2n+1)^(n-1)`：
`2n+1 ≡ 0 mod 5` 当 n ≡ 2，底数被 5 整除，整体自然被 5 整除。

真正有趣的是**没有闭式的组合序列**（A000262、Apéry 数、Bessel 多项式这类）。
它们是"新同余"的候选。

## 7. 局限与下一步

- **不能自动判断"新"**：很多模式是 Lucas/Kummer 定理或多项式因子的推论；
  判断是否为新定理需要逐例人工分析（或文献检索）。
- 只查了 m = p 的形状；m ≠ p（如 mod 5 的周期 7）尚未系统整理。
- 没查 mod p²（拉马努金的 p(25n+24) ≡ 0 mod 25 是更深一层）。
- 候选清单已保存：`reports/congruence_candidates2.txt`（4,560 条，含 p、r、点数）。

## 8. p-adic 深度：能挖多深

同一类同余可以一层层加深：`p(5n+4) ≡ 0 mod 5` 之上还有 `p(25n+24) ≡ 0 mod 25`、
`p(125n+99) ≡ 0 mod 125`…… 用 p-adic 赋值可以系统地测量"深度"：
若某个类 mod p^k 上所有项的 v_p ≥ k，就记为深度 k。

**验证：在 A000041 上逐层重现了拉马努金–Watson。**

| 层 | 类 | 最小 v₅ | 已知结论 |
|---|---|---|---|
| 1 | n ≡ 4 (mod 5) | 1 | 拉马努金 1919 |
| 2 | n ≡ 24 (mod 25) | 2 | Watson |
| 3 | n ≡ 74/99/124 (mod 125) | 3 | 多个类 |
| 4 | n ≡ 599 (mod 625) | 4 | λ₄ = 24⁻¹ mod 625 |

λ₄ = 599 与 `24λ ≡ 1 (mod 5^k)` 的公式完全吻合——**算法独立地挖出了已知定理**。

## 8.1 全库深度分布

对 4,563 条未记录候选做全分支 DFS（每层检查所有 p 个子类）：

| 深度 | 命中 | 序列 |
|---|---:|---:|
| ≥2 | 2,665 | 1,600 |
| 3 | 300 | — |
| **4** | **28** | — |

（早期版本把"零项"当成无穷大赋值，使稀疏序列的**全零子类**伪造出任意深度；
修正后 A338464 的"深度 3"消失，但 A000041 的深度 4（599 mod 625）不变。）

深度 ≥3 共 **321 条序列**（p=5 有 305 条记录、p=7 有 60 条、p=11 有 45 条）。
按名称粗分：**分拆类 23、模形式/eta 17、其他 281**。

"其他"这么多，说明**深度 5-adic 同余在组合序列里并不稀有**——
很可能有共同的机制（二项式和的 Lucas 定理、阶乘因子、多项式因子）。
这正是下一步要分类的东西。

深度 4 的 30 条里，很多是分拆函数的"亲戚"：

```
A000041  分拆数                    n≡599 mod 625
A092885  无重复部分的分拆          n≡624 mod 625
A058695  2n+1 的分拆方式数         n≡299 mod 625
A066967  所有分拆的奇部分之和      n≡599 mod 625
A133042  分拆数的立方              n≡124 mod 625
A282919  a(49n+47)                 n≡598 mod 625
```

这说明深度结构会在相关序列之间"传染"——分拆函数的同余可以迁移到它的变换上。

## 9. 为什么这件事重要

如果 4,560 条里哪怕有 1% 是真正未被记录的定理，那就是 45 条新同余——
而且是在 40 万条序列上系统扫出来的，不是靠灵感。
这条流水线可以反复运行（加 p²、加 m≠p、加多素数组合），
**把"找规律"变成可规模化的搜索**。
