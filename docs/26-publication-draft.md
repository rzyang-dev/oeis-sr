## 1. 一句话概括

对 OEIS 做了首次全库 2-自动序列普查（156,753 条），构造并验证了 636 个
显式最小 DFA，用 Cobham 定理量化了 3-/5-自动检测的误差，并在 Lean 中
对**所有 n** 证明了六条 OEIS 猜想。

## 4. 技术贡献

1. **窗口法的饱和判据**（不是大小判据），附反例：分拆计数 1,2,3,4,5,6,7 线性增长；
2. **稀疏序列伪自动机**问题及过滤（Pierpont 素数指示函数造出 19 态假自动机）；
3. **平移自动机**（`shift_correct`）：读 n 的二进制位模拟 b(n+k)，
   Lean 中证明其正确性并迭代四次用于第 5 条；
4. **右移自动机**（`halveδ`）：首位数变进位，实现 floor((n+1)/2)，用于第 6 条；
5. **Cobham 作为检测器精度检验器**（§2.3）。

## 6. 诚实的边界

- 六条 Lean 定理针对的是**我们构造的自动机**；自动机由 b-file 推断
  （全项零误差 + 最小性）。严格化需要证明自动机等于 OEIS 的字面定义。
- **已完成五条定义连接**：
  1. `lean/Conn.lean`：A043545 自动机 = (最大位 − 最小位)；
  2. `lean/PdConn.lean`：A096268 自动机 = 周期倍增递推 pd(2n)=0, pd(2n+1)=1-pd(n)。
  3. `lean/FrConn.lean`：A036987 自动机 = 「2^k − 1 的指示函数」。
  4. `lean/Conn3.lean`：A035263 自动机 = 形态词（0→11, 1→10）的轨迹。
  5. `lean/Conn4.lean`：A039982 自动机 = 形态词极限（S(0)=1, S(n+1)=1·φ(S(n))）。
  6. **A267442（Rule 129）**：定义已确认（无限网格、Rule 129、中列），
     并且**闭式已找到并穷举验证**（脚本 181/183；t ≤ 2000 零误差）：
     
     > x(t,j) = 0 ⟺ |j| ≤ t 且 ⌊(t−|j|)/2⌋ 是 r(t) 的位子掩码，r(t) = t 去掉最高位。
     
     由此中列 x(t,0) = 0 ⟺ t = 2^k − 1。闭式还满足 CA 局部递推，
     因此可形式化为纯位运算归纳（详见 `docs/30-rule129-closed-form.md`）。
     Lean 形式化进行中。
- 3-/5-自动普查的假阳性率见 §2.3；
