# OEIS 中的自动序列：一次全库普查

> 摘要：对 OEIS 中 156,753 条有 b-file 的序列做 2-自动性普查，
> 构造并验证了 636 个显式最小 DFA；对 ≥6000 项的长数据做 3-自动普查，
> 得到 335 个验证过的 base-3 自动机。用 Cobham 定理做交叉检验，
> 得到 2-自动与 3-自动判定的完美分离（198/0 对 0/42）。
> 附：Collatz 相关序列 A216059 被证明为 8 状态 2-自动。

## 1. 方法

序列 a(n) 是 p-自动的 ⟺ p-核有限。用窗口法估计核：
固定 e，取 a(r + p^e n) 的前 W 个值作为窗口，统计不同窗口数。

**判据是饱和，不是大小**：真自动序列的分层窗口数最终不变
（Thue–Morse: 1,2,2,2,2,2,2），非自动序列线性增长
（分拆计数: 1,2,3,4,5,6,7）。

## 5. 画廊：意外的自动序列

**A216059 —— Collatz 轨迹中缺失的最小数**

\`\`\`
a(n) = 最小的不在 Collatz 轨迹中的正整数，a(n) <= 7
8 状态 2-自动机：
  out = [2,2,3,2,6,3,3,7]
  trans = [[1,2],[3,4],[5,2],[3,6],[4,6],[6,7],[6,6],[7,6]]
\`\`\`

一个 Collatz 相关的序列，其值完全由 n 的低位决定。

**A151666 —— 写成不同 4 的幂之和的分拆数**：3 状态自动机。
**A089048 —— 写成恰好 3 个 2 的幂之和的方式数**：10 状态。
**A010145 —— √61 的连分数**：周期 11，但 base-2 自动机需要 **60 状态**。

## 6. 局限

1. **窗口法会过判**：3-自动的真实率只有 56%（2-自动 68%）；
2. **留出验证不可行**：半数据构造对长周期序列会退化成 1 个状态
   （A016266 周期 > 1500，准确率 0%）；
3. 可靠证据 = 全数据构造 + 全项预测 + 最小性。
