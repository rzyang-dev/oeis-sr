# A156886 的同余：一条完整证明

> 这是"同余发现流水线"找到并证明的第二条定理。
> 对象：`a(n) = Sum_{k=0..n} C(n,k) * C(3n+k, k)`，OEIS A156886。

## 1. 定理

对任意 m ≥ 0：

```
a(5m + 1) ≡ 0 (mod 5)
```

b-file 的 938 项全部验证通过。

## 2. 关键恒等式

```
a(n) = [y^(3n)] (1+y)^(3n) (2+y)^n
```

**证明**：由 `C(n,k) = [x^k](1+x)^n` 与 `C(3n+k,3n) = [y^(3n)](1+y)^(3n+k)`，

```
a(n) = Σ_k [x^k](1+x)^n [y^(3n)](1+y)^(3n) (1+y)^k
     = [y^(3n)] (1+y)^(3n) Σ_k [x^k](1+x)^n (1+y)^k
     = [y^(3n)] (1+y)^(3n) (1 + (1+y))^n
     = [y^(3n)] (1+y)^(3n) (2+y)^n
```

（前 60 项数值验证通过。）

## 3. 证明

设 n = 5m + 1。在 F_5 上用 freshman's dream：

```
(1+y)^(15m+3) = (1+y)^3 · ((1+y)^5)^(3m) ≡ (1+y)^3 (1+y^5)^(3m)
(2+y)^(5m+1)  = (2+y)   · ((2+y)^5)^m    ≡ (2+y)   (2+y^5)^m
```

第二个因子 `(1+y^5)^(3m)(2+y^5)^m` 的指数都是 5 的倍数，而我们要取 y^{15m+3}，
所以只能从 `(1+y)^3(2+y)` 取 y^3：

```
a(5m+1) ≡ [y^3](1+y)^3(2+y) · [y^(15m)](1+y^5)^(3m)(2+y^5)^m   (mod 5)
```

而

```
[y^3](1+y)^3(2+y) = 2 + 3 = 5 ≡ 0   (mod 5)
```

所以 `a(5m+1) ≡ 0 (mod 5)`。∎

更精确地：`a(5m+1) ≡ 5·a(m) ≡ 0 (mod 5)`，
因为 `[y^(15m)](1+y^5)^(3m)(2+y^5)^m = [z^(3m)](1+z)^(3m)(2+z)^m = a(m)`。

## 4. 一个被数值测试否定的过度推广

本文档初稿曾猜想"对每个 r，`a(5m+r) ≡ a(m)·c_r`，其中 c_r = [y^(3r)](1+y)^(3r)(2+y)^r"。
数值测试立即推翻：n=7,8,9 就不成立。

原因：r ≥ 2 时 `[y^(3r)]` 可以拆成多个 j（j ≡ 3r mod 5，但 j 可到 4r），
不是一个单一项。只有 r = 0, 1 是干净的。

**这个例子说明：证明方向必须每一步都接受数值检验。**

## 6. 另外两条一行证明：周期递推

对 115 条 Z={1} 候选做 mod 5 周期检查（周期 5），9 条是周期的：
A019566、A056545、A095740、A108189、A144500、A182386、A288268、A331725、A332562。

周期递推序列的同余可以一行证明。

**A182386**：`a(0)=1, a(n)=1-n·a(n-1)`。

对 n ≥ 1 归纳证明 `a(n+5) ≡ a(n) (mod 5)`：

```
a(n+5) = 1-(n+5)a(n+4) ≡ 1-n·a(n+4) ≡ 1-n·a(n-1) = a(n)   (mod 5)
```

（归纳假设用 `a(n+4) ≡ a(n-1)`。）
于是 `a(5m+1) ≡ a(1) = 0 (mod 5)`。∎

**A056545**：`a(0)=1, a(n)=4n·a(n-1)+1`。

```
a(n+5) = 4(n+5)a(n+4)+1 ≡ 4n·a(n+4)+1 ≡ 4n·a(n-1)+1 = a(n)   (mod 5)
```

同样 `a(5m+1) ≡ a(1) = 5 ≡ 0 (mod 5)`。∎

两条序列 mod 5 的余数模式都是 `1,0,1,3,4` 循环。
