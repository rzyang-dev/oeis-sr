# 查询文件

返回指定文件的信息。

## 接口

```http
GET /files/{file_id}
```

operationId: `retrieveFile`

### 服务地址

- `https://api.deepseek.com`

## 身份验证

### 验证方式 1

**bearerAuth**

`Authorization: Bearer <API_KEY>`

```yaml
type: http
scheme: bearer
```

## 请求参数

**`file_id`** (path) — 必填

要查询的文件 ID。

- `type`: `string`

## 响应

### 200

OK, 返回 `file object`。

#### application/json

- 引用: [FileObject](#schema-file-object) (`#/components/schemas/FileObject`)

**示例**

```json
{
  "id": "file-api-0a1b2c3d4e5f60718293a4b5c6d7e8f9",
  "object": "file",
  "bytes": 102400,
  "created_at": 1700000000,
  "filename": "image.jpg",
  "purpose": "user_data"
}
```

## 代码示例

### curl

```bash
# Set DEEPSEEK_API_KEY to your API key before running this example.
# Set DEEPSEEK_FILE_ID to the id returned by the upload example.
curl --silent --show-error --max-time 60 "https://api.deepseek.com/files/${DEEPSEEK_FILE_ID}" \
  --header "Authorization: Bearer ${DEEPSEEK_API_KEY}"
```

### Python — OpenAI SDK

```python
# Set DEEPSEEK_API_KEY to your API key before running this example.
# Set DEEPSEEK_FILE_ID to the id returned by the upload example.
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    base_url="https://api.deepseek.com",
    timeout=60.0,
)

info = client.files.retrieve(os.environ["DEEPSEEK_FILE_ID"])
print(info.model_dump_json(indent=2))
```

## 引用的数据结构

### schema-file-object

**FileObject** — `#/components/schemas/FileObject`

描述一个已上传到 Files API 的文件。

- `type`: `object`

- `required`: `["id","object","bytes","created_at","filename","purpose"]`

- **字段**

  - **`id`** (必填)

    文件标识符，形如 `file-api-...`，可在对话补全请求中引用。

    - `type`: `string`

  - **`object`** (必填)

    对象的类型，其值为 `file`。

    - `type`: `string`

    - `enum`: `["file"]`

  - **`bytes`** (必填)

    文件大小（字节）。

    - `type`: `integer`

  - **`created_at`** (必填)

    文件创建时的 Unix 时间戳（以秒为单位）。

    - `type`: `integer`

  - **`filename`** (必填)

    文件名。

    - `type`: `string`

  - **`purpose`** (必填)

    文件的用途。

    - `type`: `string`

    - `enum`: `["user_data"]`

  - **`expires_at`** (可选)

    文件过期时的 Unix 时间戳（以秒为单位）。仅在上传时设置了过期时间才会出现。

    - `type`: `integer`
